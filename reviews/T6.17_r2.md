## 관련 개선 및 회귀 확인

- `GuidePlayer.tsx:304–311`의 카운터는 role=img를 제거하고 시각 숫자를 aria-hidden으로 숨긴 뒤 번역된 guide.part를 sr-only 텍스트로 제공한다. 기존 `styles/global.css:110`의 sr-only는 화면 읽기용 내용을 display:none 또는 visibility:hidden으로 제거하지 않는다. 숫자와 문구를 중복해서 읽거나 숫자를 이미지라고 알리는 기존 표현 문제를 개선했다.
- grid stage와 모든 묶음의 동일 셀 배치는 유지되어 비활성 묶음도 높이 계산에 참여한다. reduced-motion 규칙은 활성·비활성 묶음 양쪽의 transition과 transform을 제거한다. CSS 변경으로 재생 상태나 페이지 계산 로직이 바뀌지 않았으며 새 상태 전이 결함은 발견하지 못했다.
- `guideChunks.test.ts:20–25`에 상한과 같은 길이 및 1자 초과의 기대값이 추가되어 `<=`를 `<`로 바꾸는 경계 변이를 구분한다. 실제 원고 전체에서 각 문장 번호의 chunkOf 값이 해당 묶음 번호와 일치하는지도 확인한다. 이번 검토에서 변이 파일을 만들거나 변이 실행을 하지는 않았다.
- `GuidePlayer.test.tsx:305–313`은 닫았다 다시 열 때 첫 묶음·0번 문장 재생을 확인한다. CSS 테스트는 stage의 display:grid, 비활성 transition:none, 활성 전환, visibility, reduced-motion을 검사하도록 보강됐다. 실제 브라우저의 표시·레이아웃을 측정하는 테스트는 아니지만 R1에서 지목한 선언 삭제 및 지연 숨김 회귀에 대한 검출 범위는 넓어졌다.
- `prd.md:187` F-19가 “최대 2문장씩”, “다음 묶음”으로 바뀌어 홀수 문단 및 길이 상한에 따른 한 문장 묶음과 정합한다. DESIGN의 즉시 숨김·새 묶음 표시·일반 행동 버튼 설명도 현재 코드와 일치한다.
