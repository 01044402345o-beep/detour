### R2-L01 검증

`ui/overlay.test.ts`에서 다음을 확인했고 대상 테스트 실행도 통과했다.

- CSS display:none 및 visibility:hidden 조상 아래 컨트롤 제외.
- disabled+tabindex=0, 음수 tabindex, disabled fieldset 내부 input, hidden/inert 조상 제외.
- 숨김 요소가 앞뒤에 있어도 실제 첫/마지막 컨트롤 사이 Tab·Shift+Tab 순환.
- focus 실패 시 다음 후보 시도 및 모든 후보 실패 시 컨테이너 복귀.

R2에서 실제로 확인했던 후보 과포함 문제에 대응하는 수정과 회귀 검사가 갖춰졌다. jsdom 검사와 실제 브라우저에서 클래스로 숨긴 ReportSheet 컨트롤 검사는 usage에서 구분하며, 후자는 예정된 Phase 2 E2E 확인 사항으로 남는다.

### R2-L02 심각도 및 범위 조정

**Low→nit 조정에 동의한다.** 현재 계획된 제보 시트와 장소 전환 확인 시트는 서로를 여는 흐름이 없고, 열린 시트의 배경은 inert다. 따라서 공용 컴포넌트의 지원 계약을 단일 시트로 좁히는 것은 현재 제품 범위에 맞는다.

이는 겹침 동작 자체를 고쳤다는 판정은 아니다. 역순 열림의 쌓임 순서·아래 시트 접근성 문제는 겹침을 지원하지 않는 계약 밖에 남으며, DEV 경고도 두 번째 시트를 강제로 막지는 않는다. 사용 안내가 이를 분명히 했고 판정서가 요구한 처리와 일치하므로 미해결 결함으로 유지하지 않는다. 향후 겹침이 필요해지면 기존 스택·카운터만으로 지원된다고 간주하지 말고 별도 구현·검증해야 한다.

## 신규 문제 및 회귀

- 이번 수정 범위에서 신규 수정 필수 문제는 발견하지 못했다.
- inert의 토스트 role=status 제외, 기존 inert 보존, 마지막 release의 배경 복원 방식은 유지됐다. 겹침 카운터는 지원 기능이 아닌 실수에 대한 안전장치로 설명된다.
- DEV 경고 테스트는 첫 시트에서 경고 없음, 두 번째 시트에서 경고 발생을 확인한다. 개발용 영어 경고는 사용자 UI 문구가 아니므로 번역 누락으로 분류하지 않는다.
- usage는 이전 테스트 수·타입 요약을 최초 결과로 표시하고 최신 사용 계약을 따르도록 정리했다. default 화면을 memo/forwardRef로 바꿀 때 테스트 계약을 조율하라는 안내도 반영됐다.
