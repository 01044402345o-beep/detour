## 1. 수정 (`app/src/sw/pwa.ts`)

| 항목 | 내용 |
|---|---|
| 취소 신호 전달 | `PwaDeps.readStatus`를 `(signal?: AbortSignal) => Promise<PrecacheStatus \| null>`로 넓힘(선택 인자라 기존 대역 호환). `checkOnce`가 판정마다 `AbortController`를 만들어 넘기고, 8초 시간 제한(`withTimeout`의 만료 콜백)에서 `abort()` |
| ready 뒤 확인 | `readStatusFromWorker(signal)`: `await navigator.serviceWorker.ready` 직후와 활성화 대기 직후 `signal.aborted`면 `null` — **`postMessage`를 보내지 않음** |
| 활성화 대기 정리 | `waitActivated(sw, signal)`: 취소되면 `statechange` 리스너와 abort 리스너를 지우고 바로 끝냄 (이미 취소된 경우 리스너를 달지 않음) |
| 응답 대기 정리 | 응답 수신·5초 응답 제한·취소 어느 경우든 `clearTimeout`, abort 리스너 제거, `port1.onmessage = null`, `port1.close()` 후 끝냄 |
| 바꾸지 않은 것 | 재시도 간격·상한(1·2·3·5초, 60회), 8초 시간 제한, 한 번에 하나만 판정·rerun 병합, 준비 완료 기준(`total>0 && cached===total`), `sw.ts` |

`readStatusFromWorker`는 회귀 테스트가 실제 경로를 쓰도록 export했습니다(동작 변화 없음).
