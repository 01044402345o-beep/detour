## 발견 사항

### L-01 — 녹음 고리 예외의 상태 범위가 실제 구현보다 좁음 (R1 M-01 잔여)

- 위치: `DESIGN.md:100`, `app/src/screens/Practice/index.tsx:49`, `:150`, `:318`, `app/src/screens/Practice/practice.css:314`.
- 새 예외는 **“마이크가 듣는 중일 때의 파형·고리 반복 표시”**만 허용한다. 파형은 `stt.status === 'listening'`에만 켜지지만 마이크 고리의 `on` 클래스는 `active`를 사용하며, `ACTIVE`에는 `requesting`, `listening`, `processing`이 모두 들어 있다. 따라서 권한/시작 대기와 인식 처리 중에도 `pr-pulse ... infinite`가 실행된다.
- 확인 경로: 마이크 사전 고지 승인 후 아직 `onstart`가 오지 않은 requesting 상태, 또는 `onspeechend` 이후 결과를 기다리는 processing 상태. 해당 상태에서도 마이크 버튼은 `pr-micb on`이다. 상태 전이 자체는 기존 Practice 테스트가 검증하지만 애니메이션 적용 범위는 검사하지 않는다.
- 권장 조치: 고리 애니메이션을 listening 전용 클래스/조건으로 분리하되, active의 정지 버튼·취소 동작은 그대로 유지한다. 세 상태 모두의 기능 표시를 유지하려는 결정이라면 coordinator가 예외 문구에 requesting·processing까지 명시하면 된다.
- 심각도 근거: reduced-motion에서 모두 꺼지고 상태 문구·정지 아이콘도 유지되므로 기능·접근성 중대 회귀가 아니라, R1 판정 후 남은 문서/구현 정합성 문제로 L로 분류했다. 듣는 중 반복 표시 자체를 다시 문제 삼는 것은 아니다.

## 요구 사항·회귀·테스트 검토

- 밝은 바탕·흰 목록·파란 주 버튼·선 구분·고정폭 숫자가 공통 시안 체계를 따른다. T6.6 전용 시안은 없어 `mockup/redesign/c2-order.png`를 직접 열어 공통 색·글자·버튼 구성을 대조했다. 저장 빈 화면의 저장 방법 안내, 문장 모음의 코스별/장소별 묶음과 한국어→발음→뜻 구조가 유지된다.
- 설정의 시연 도구는 기본 접힘이며 aria-expanded/aria-controls로 상태를 전달한다. 언어 즉시 전환·리포트 진입·초기화 확인·정정 안내·연락처 조건부 표시를 유지한다. 사진 출처는 새 라우트 없이 Sheet에서 PHOTOS를 읽어 제목·저작자·연도·라이선스/원본 링크·고지·변경 내역을 표시한다. 옆 장소명과 중복인 썸네일의 빈 alt, lazy loading, 외부 링크 rel도 적절하다. 사진 위 글자가 없어 scrim 규칙의 직접 적용 대상은 아니다.
- diff에서 기존 이벤트·라우팅·북마크·정보 제보 핸들러 및 testid 삭제를 발견하지 못했다. 마이크 사전 고지·미지원/거부/무음/시간 초과 대응, 정상/느린 TTS, 결과 인식 일치도 설명·다시 하기·다음 문장·직원 화면 진입이 유지된다. 단어 결과는 색 외 체크/엑스와 낭독 문구를 제공한다. Saved의 확인 전/확인일 표시도 유지된다.
- 주요 글자 색은 blue/white, blue/tint, mute/ground, danger/white 등 기준 대비를 충족하는 조합이다. 44px 조작 영역, 3px 초점선, 공용 Sheet의 초점 순환·복귀 계약을 코드와 관련 테스트로 확인했다. 실제 픽셀별 대비나 모든 키보드 경로를 이번에 브라우저에서 재측정한 것은 아니다.
- 테스트 diff는 바뀐 머리말·링 색·시연 도구 펼침 전제 갱신과 신규 동작 검증이다. 기존 동작 테스트 삭제는 없다. 사진 출처 열기/닫기/Esc/뒤로가기/초점 복귀 테스트가 통과한다. 다만 MemoryRouter 기반이므로 실제 HashRouter와 history 상호 작용까지 독립적으로 보장하는 검증은 아니다.
- `app/e2e/s5-lang-switch.spec.ts:68`의 직접 `open-report` 클릭은 아직 접힘 구조와 맞지 않는다. 이미 R1·작업 보고에서 T6.7 소유로 이관한 갱신 사항이므로 새 결함으로 중복 집계하지 않았다. T6.7에서 `demo-tools`를 먼저 펼친 뒤 전체 E2E를 실행해야 한다.
- 번역 패치의 세 언어 구조·적용 결과·override 세 개를 확인했고 누락 키 또는 의미 손상을 발견하지 못했다. 공유 작업 트리 특성상 모든 변경의 작성자를 귀속할 수는 없지만, 작업 보고와 대상 diff에서 승인된 Report 예외 외 추가 범위 위반 근거는 없었다.
