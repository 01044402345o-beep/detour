## R2-L-01 — 타당, nit으로 조정

**근거**
- `operatorKo.ts:6`은 "`formatKo(template, params)`로 채웁니다"라고 안내하지만, 실제 함수는 `operatorKo.ts:48`의 `formatKo(key: OperatorKoKey, params?)`입니다. 주석이 틀린 것은 사실입니다.
- 주석대로 `formatKo(OPERATOR_KO.deviceEvents, …)`를 쓰면 문자열 값이 `OperatorKoKey`에 할당되지 않아 **타입 검사에서 바로 실패**합니다. 조용히 잘못 동작하는 경로가 없고, 아직 이 함수를 쓰는 화면도 없습니다. 그래서 동작 결함(Low)이 아니라 문서 정확성 문제(nit)로 봅니다.

**수정 지침** (`operatorKo.ts:6` 한 줄 교체, 동작·테스트 변경 없음)

현재:
```
 * - `{name}` 자리표시자는 formatKo(template, params)로 채웁니다(누락 시 개발 모드 경고, t()와 같은 규칙).
```
대체:
```
 * - `{name}` 자리표시자는 formatKo(key, params)로 채웁니다. 예: formatKo('deviceEvents', { count: 3 }).
 *   누락 시 개발 모드 경고(t()와 같은 규칙). 자리표시자 없는 문구는 OPERATOR_KO.title처럼 상수를 그대로 씁니다.
```
