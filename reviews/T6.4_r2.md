## 기준·회귀·범위 검토

- 사진 머리/파란 글자 머리, 출처, 진행 표시, 탭, 선택된 메뉴 줄, 중립색 닫힘·가격 미정·알레르기, 담은 항목이 있을 때만 주문 바라는 구성을 유지한다. 사진 글자 영역의 막은 위 28px 전환 구간 아래 40px 패딩에서 글자가 시작하여 코드상 0.86 이상이며 출처는 11.5px다.
- 사진은 언어별 의미 있는 alt와 eager 로딩을 사용한다. 새 색 토큰, 공용 44px 터치 영역, 탭 최소 높이 46px, 초점 표시, 전역 및 장소 화면 reduced-motion 규칙을 확인했다. 최악 사진 배경의 실제 합성 대비 4.5:1 계측은 이번에 수행하지 않았으며 T6.7 검증 항목이다.
- 현장 확인 전 안내/확인일, 영업 상태 참고 안내, 비제휴·정정 안내, 메뉴 예시 가격·미정 가격·알레르기 정보를 유지한다.
- 수량 조작·최대 수량, 장소 변경 확인, 주문 바 이동, 저장·제보, `place_view`·`phrase_play`, 문장 탭에서 연습으로 전달하는 navigation state에서 새 회귀를 발견하지 않았다. 기존 screen/menu/orderbar/verified/phrase testid 계약은 유지된다.
- 테스트 diff는 제거된 떠 있는 연습 버튼과 바뀐 표시 문구의 기대를 갱신하며, 문장 탭 → 연습 및 기존 기능 검사를 보존한다. R1 수정 검사가 추가됐고 기존 검사를 삭제하거나 완화한 흔적은 없다. CSS 클래스 검사는 실제 글꼴 로드·레이아웃 검증을 대신하지 않는다.
- T6.4 번역 패치는 place/menu 이름공간의 언어별 10개 키이며 적용된 en/ja/zh.json 값과 모두 일치한다. 검토 범위에서 누락 키나 원시 키 노출을 발견하지 않았다.
- 작업 보고에 명시된 변경과 새 `numText.tsx`는 소유 범위 안이다. 공유 작업 트리의 다른 화면·공용 파일 변경을 T6.4의 수정으로 귀속할 근거는 없으며 이번 판정에서 제외했다.
