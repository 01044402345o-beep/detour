## R2-L01 (Low, 필수) — 포커스 후보 필터 (`app/src/ui/overlay.ts`)
- 선택자 `a[href], button, input, select, textarea, [tabindex]`로 후보를 모은 뒤 `isTabbable(el, root)`로 거름:
  `tabIndex < 0` 제외(-1·-2 …), `:disabled` 제외(disabled 속성·disabled fieldset), `[hidden]`·`[inert]` 조상 제외, 자신~시트 루트까지 계산 스타일 `display:none`·`visibility:hidden` 제외. `getClientRects`는 jsdom에서 항상 비어 쓰지 않음.
- 안전장치: `trapTab`이 순환 대상에 `focus()` 후 `document.activeElement`가 대상이 아니면 같은 방향 다음 후보를 시도하고, 모두 실패하면 시트 컨테이너(`root.focus()`)에 붙잡음.
- 테스트 신규 `app/src/ui/overlay.test.ts`(3개): ① display:none·visibility:hidden 조상, `disabled tabindex="0"`, `tabindex="-2"`, disabled fieldset 안 input, hidden·inert 조상, href 없는 a 제외 ② 숨김 버튼이 맨 끝일 때 실제 마지막 → Tab → 첫 요소, 맨 앞일 때 첫 실제 요소 → Shift+Tab → 마지막 ③ focus 실패 시 다음 후보, 모두 실패 시 컨테이너.
- 클래스로 숨긴 실제 브라우저 경우는 Phase 2 E2E에서 ReportSheet로 1회 확인(usage에 구분해 기록).
