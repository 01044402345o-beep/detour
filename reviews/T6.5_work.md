## 결정·주의
- **직원 문장 글자 크기**(`staffFontSize(ko, level)`, 3단계): 짧은 문장(14자 이하) 56/64/72, 보통(28자 이하) 44/56/64, 긴 문장 36/44/56. 기본은 가운데 단계. 메뉴 여러 개를 담은 긴 문장은 기본값이 44px(56 미만)인데, 360×780에서 응답 버튼까지 거의 한 화면에 들어오게 하려는 것이고 A+로 56까지 키울 수 있음. 함수 시그니처가 `(ko, big: boolean)` → `(ko, level?: number)`로 바뀜(쓰는 곳은 Staff 화면·테스트뿐)
- **수와 단위 줄바꿈 방지**: `keepCountersTogether()`(staffContent.ts)로 화면에 보이는 문장에서만 "한 개"의 띄어쓰기를 줄바꿈 없는 공백으로 바꿈(주문 카드·직원 화면). 읽어주기(TTS)·기록·연습에는 원문을 씀. 단위는 하드코딩하지 않고 메뉴 데이터의 `counter`에서 가져옴
- **A−/A+ 글자**: ja·zh 사전 검사(영어와 같은 값 금지, 각 언어 문자 필수)를 통과할 수 없어 번역 키로 두지 않고 CSS `content`로 그림(장식). 버튼 이름은 번역된 aria-label. 처음에 `staff.sizeDown/sizeUp` 키를 패치로 넣었다가 i18n 검사에서 걸려, 패치에서 빼고 세 json에서도 잠금을 잡은 뒤 이 두 키만 지움(내가 방금 추가한 키라 다른 task 영향 없음). 지금 en/ja/zh에 없음
- "Listen slowly (0.75×)"는 `audio.*`(내 이름공간 아님) 문구 그대로라 좁은 칸에서 두 줄이 됨. 시안처럼 "Listen slowly"로 줄이려면 T6.0/coordinator 판단 필요
- 시안의 "매장에서 먹어요" 요약은 한국어 고정 문구가 `i18n/staffKo.ts`(공용)에 없어 넣지 않음. 포장일 때 "포장"만 기존처럼 표시
- 대비(직접 계산): `--mute` on `--line`(세그먼트 비선택) 4.76:1, 흰 글자 on `--blue-deep` 10.39:1, `--blue-deep` on `--tint`(다음 행동) 9.2:1 이상, 파랑 on 연파랑 5.11:1
