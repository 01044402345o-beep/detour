## 결정

- **사진 출처 시트의 뒤로가기:** 새 경로 없이 열 때 `history.pushState(history.state, '', 같은 주소)`로 한 칸 쌓음. 라우터 key가 같아 screen_view·토스트 정리가 다시 돌지 않음. 뒤로가기(popstate) → 시트만 닫힘, 닫기·Esc·바탕 탭 → 쌓은 칸을 `history.back()`으로 되돌림. 실제 브라우저(Edge, 포트 5196)에서 뒤로가기 후 `#/settings` 그대로·dialog 0개 확인.
- **사진 출처 항목:** 장소(장소 데이터 이름 / 코스 출발지 이름 / 권역 사진은 `settings.photoArea.*`), 원본 제목·저작자·연도·고지·변경 내역은 `data/photos.ts` 값 그대로(`lang="en"`), 라이선스 링크 글자 = `licenseId`, 원본 링크 글자 = 원본 파일 이름(`File:….jpg`, `sourceUrl`에서 만듦). 라벨은 `photo.*`(T6.0) + `settings.photo*`. 썸네일은 옆에 장소 이름이 있어 빈 alt, `loading="lazy"`. 링크는 새 탭 + `rel="noopener noreferrer"`, 높이 44px.
- `photo.source`("Photos: Wikimedia Commons")는 시트에서 쓰지 않음(링크 글자로는 어색).
- 시연 도구 안 초기화는 `--danger`를 쓰지 않음(오류가 아니므로, 확인 시트로 보호).
