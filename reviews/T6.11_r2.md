## L-01 — ‘한 번만 이동’ 테스트가 중복 navigate를 여전히 놓침

- 위치: `app/src/screens/Home/Home.test.tsx:126–137`, 관련 기록 방식 `app/src/router/AppRoutes.tsx:17–29`.
- R1 L-02의 SVG 클릭과 `screen_view = ['home', 'course']` 검증은 추가됐다. 하지만 navigate 호출 횟수나 이력 증가 횟수 검증은 없다. 같은 클릭에서 버튼과 부모 article이 각각 navigate하면 React가 갱신을 묶으므로 라우터의 effect는 최종 location만 관찰할 수 있다. 따라서 화면 이벤트가 한 번이라는 사실로 이력도 한 칸만 쌓였다고 판단할 수 없다.
- 파일을 생성·수정하지 않고, 설치된 React 19.3.1·react-router-dom 7.18.6·jsdom으로 동일한 MemoryRouter/부모 article/자식 button 구조를 메모리에서 재현했다. 두 핸들러 모두 `/course`로 이동하게 하면 출력은 `navigateCalls: 2, views: ['/', '/course']`였다. 뒤로 한 번 이동한 뒤에도 `/course`에 남았다. 이는 현재 검증식의 사각지대를 확인한 것으로, 제품 코드를 변경한 mutation test는 아니다.
- 수정 권고: 기존 SVG 클릭 및 screen_view 검증을 유지하고 navigate 호출이 정확히 1회인지 spy로 확인하거나, 클릭 후 뒤로 한 번 이동하면 홈으로 돌아오는지 검증한다. `closest('button')` 방어를 제거하면 실패하는 테스트여야 한다.
- 현재 `Home/index.tsx:137–140`은 버튼 내부 SVG에서도 `closest('button')`으로 부모 이동을 건너뛰므로 실제 중복 이동 버그는 없다. 회귀 검증 공백이므로 L이다.

## 대비·화면·접근성

- `--scrim-rgb: 8, 20, 46`을 불투명도 0.62로 완전한 흰 사진 위에 합성하면 RGB `(101.86, 109.30, 125.42)`이다. sRGB 선형화 후 상대휘도 `0.153094316`, 흰 글자 대비 `1.05 / (0.153094316 + 0.05) = 5.170011748:1`로 다시 계산했다. DESIGN 5장의 ‘약 5.1:1’은 맞고, 그림자 없이도 4.5:1을 넘는다.
- Home 글자 박스 자체는 .62~.80 배경이며 56px 페이드는 `::before { bottom:100% }`로 박스 밖에 있다. 글자는 padding-top 10px 안쪽 정상 flex 흐름이다. Place는 위 72px 페이드와 padding-top 72px가 일치하며 글자는 그 아래 .62~.82 구간에 놓인다. min-height 구조라 줄바꿈에 따라 박스가 확장되고, 음식 예시 띠의 별도 .92 배경도 유지된다.
- `home-360-{en,ja,zh}.png`, `place-gwc-360-{en,ja,zh}.png`, `place-mus-360-{en,ja,zh}.png` 및 `mockup/redesign/c2-home.png`, `c2-place.png`를 확인했다. 대전역 카드의 요약·출발 안내·시작 버튼, 사진 상부 노출 증가와 하단 글자 막은 이번 사용자 요청에 부합한다. 긴 전시관 이름과 JA/ZH 이름·출처도 제공된 화면 안에 들어간다.
- 캡처는 720×1560 이미지로 제공된 360px 화면이며 전체 페이지 캡처는 아니다. 홈의 유성 카드·원도심 시작 버튼 등 화면 아래 영역을 이 이미지로 직접 확인했다고 주장하지 않는다. 판정 보고의 `scrollWidth 360`, 넘침 0·페이드 침범 0 DOM 측정은 작성자의 결과이며 이번에는 재측정하지 않았다. 보이는 영역의 이미지 확인과 전체 공통 CSS 구조 검토를 구분했다.
- 대전역 `article` 안에는 native 시작 버튼 하나만 있고 중첩 상호작용 요소가 없다. 키보드 사용자는 내부 버튼으로 같은 코스에 진입한다. h1 → 대전역 h2 → 원도심 h2 순서이며, 두 시작 버튼은 각각 코스명으로 `aria-describedby`가 연결된다. 공통 버튼 52px 높이·44px 최소 터치·3px 초점, 전역 reduced-motion 규칙을 재사용한다.
- 사진 alt·출처와 확인 전/예시 정보·비제휴·가격·알레르기 안내 로직은 변경하지 않았다. 장소 캡처에서 확인 전 안내와 예시 가격/가격 문의 표시도 유지된다. 색·글자 토큰 변경은 없으며 흰 알약의 그림자 제거는 적절하다.

## 기능·범위·테스트

- PRD F-02·F-18/S01의 두 코스 진입, 야시장 기간 조건과 F-04/S03·S04 장소 동작은 유지된다. `hub-station`, `hub-downtown`, `home-start`는 그대로이고 `home-start-market`만 추가됐다. E2E의 기존 홈 진입은 `hub-downtown`을 사용하며 단일 시작 버튼 이름에 의존하는 선택자는 발견하지 않았다.

- EN/JA/ZH의 기존 `home.startCourse`, `home.startsAt` 및 코스 현지화 데이터를 재사용한다. 새 키/번역 패치가 없는 것은 지시와 일치한다.
