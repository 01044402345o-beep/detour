# T2.6 `ui/ReportSheet` props 계약 (T2.3용)

> 소유: T2.6. T2.3(장소 상세)은 import만 합니다. 바꿔야 하면 coordinator를 통해 T2.6에 요청.

## import
```tsx
import { ReportSheet } from '../../ui/ReportSheet';
```
(`ui/index.ts` barrel은 T2.0 소유라 등록하지 않았습니다 — 파일 경로로 직접 import)

## props
```ts
type ReportSheetProps = {
  open: boolean;
  /** 바탕·Esc·닫기 버튼, 그리고 제보를 보낸 뒤에도 호출 → 부모가 open=false로 */
  onClose: () => void;
  /** 제보 대상 장소 ID (downtown.json 실제 ID, 예 'ssd'). 생략하면 장소 없는 일반 제보 */
  placeId?: string;
  /** 제보 저장 직후 호출 (선택). kind = 'closed' | 'menu' | 'price' | 'other' */
  onSent?: (kind: ReportKind) => void;
};
```

## 사용 예 (장소 상세)
```tsx
const [reportOpen, setReportOpen] = useState(false);
<IconButton icon="flag" label={t('report.open')} onClick={() => setReportOpen(true)} />
<ReportSheet open={reportOpen} onClose={() => setReportOpen(false)} placeId={place.id} />
```

## 동작
- 공용 `Sheet`(제목 `report.title`) 위에 4종 버튼(`report.closed/menu/price/other`, 목업 순서).
- `placeId`가 데이터에 있으면 부제: `장소 이름(사용자 언어) · 확인일` — 장소 `verified:false`면 확인일 대신 `place.unverified`("현장 확인 전 · 예시 정보").
  데이터에 없는 ID면 부제 없이 장소 없는 제보로 저장합니다.
- 항목 클릭 → `store.addReport(kind, placeId)` → `onSent?.(kind)` → `onClose()` → 토스트 `report.thanks`.
- **`report_sent` 이벤트는 `store.addReport`가 함께 기록**합니다. 호출하는 화면은 `logEvent({type:'report_sent'})`를 따로 부르지 마세요(이중 기록).
- 운영자 리포트의 "내 기기 제보 건수"는 `reports.length` 기준이라 바로 +1 됩니다.
- 토스트를 쓰므로 `ToastProvider` 안(앱 틀 = AppLayout)에서 렌더해야 합니다. 테스트에서는 `ToastProvider`로 감싸세요.
- 테스트 셀렉터: 각 버튼 `data-kind="closed|menu|price|other"`, 부제 `data-testid="report-sheet-place"`, 바탕 `data-testid="sheet-dim"`(공용 Sheet).
