## 4. 결정 (검토 요청)

1. **정류장 줄의 알약(FOOD/SIGHTS·메뉴 수·문장 수) 제거** — 시안에 없고 작은 대문자 알약(`place.food` "FOOD")이 DESIGN 3장 금지 항목. 기존 테스트 "주문 가능한 장소만 메뉴 수, 모든 장소에 문장 수"는 새 줄 구성(이름·한국어 이름·동네, 알약 없음) 검사로 바꿈. 메뉴·문장은 장소 화면에서 그대로 보임.
2. **지도 위 장소 이름표(시안의 `성심당`·`으능정이` 등)는 넣지 않음** — 번호 핀과 바로 아래 목록으로 같은 정보가 있고, 시장 코스처럼 수십 m 간격에서는 이름표가 핀·칩과 겹칠 위험이 큼(DESIGN 9장 겹침 금지). 출발지 이름표(대전역)만 유지.
3. **시안의 "Full map" 버튼·저장(북마크) 버튼은 만들지 않음** — 기존에 없는 기능이고 task 범위 밖. 오른쪽 위는 기존 문장 모음 버튼 유지.
4. **구간 분 칩 배치 규칙**: 구간 경로 길이의 50%→40/60→30/70→20/80% 지점, 각 지점에서 선 위 → 선 양옆(수직으로 칩이 선에 닿지 않을 만큼) 순으로 후보를 보고, 핀(벌린 위치 기준)·출발 표시·이름표·다른 칩과 겹치지 않고 지도 상자(타일 지도는 출처 막대 위) 안인 첫 자리에 둠. 자리가 없으면 그 칩만 숨김(분은 목록에 늘 있음). 타일 지도는 줌이 바뀔 때마다 다시 계산. 실제 화면에서 원도심 390px 3~4개, 360px 3~4개, 시장(타일) 2~3개, 약도 3~4개가 보임.
5. **`zoomSnap: 0.25`** — 정수 줌이면 360px에서 한 단계 작게 맞춰져 경로가 지도 가운데 작게 보이고 칩이 1개만 들어갔음. 0.25 단위로 바꾸니 390·360 모두 경로가 지도를 채움. 타일 실패 판정(현재 줌 반올림 = 기존 `tileZoom()`)·핀 벌림 테스트 모두 그대로 통과.
6. 확인 전 안내 혼합 시 코스 요약 줄을 없앰 — 기존 테스트 "한 곳이라도 확인 전이면 코스 전체도 확인 전 표시"를 DESIGN 6장 정책(혼합 = 정류장마다)에 맞게 바꿈. 모두 미확인 경우는 시장 코스로 새 테스트.
7. `course.from`("Start · Daejeon Stn")은 쓰지 않게 됨(키는 지우지 않음). 요약에는 새 키 `course.metaFrom`("Start: {start}").
