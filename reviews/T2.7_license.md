# T2.7 Remotion 라이선스 조건 확인

- 확인일: 2026-11-23 · 작성: Claude worker (T2.7) · R1 L-01 반영(v4.0 약관 검토 추가, 근거 구조 정정)
- 대상 버전: `remotion` / `@remotion/*` **4.0.545** (`video/package.json`)

## 결론

**무료 라이선스(Free License) 대상입니다. 유료 Company License는 필요하지 않습니다.** (전제: 개인 1인 제작, 영리 단체 명의 아님)
이 프로젝트는 개인(1인)이 경진대회 심사용 데모 영상을 만드는 용도이며, 무료 라이선스 자격의 "개인(individual)"에 해당합니다. 상업적 이용도 무료 라이선스에서 허용됩니다.

단, 아래 '다시 확인할 때'에 해당하면 다시 판단해야 합니다.

## 지켜야 할 조건 (현재 적용: LICENSE.md + v4.0 약관)

1. Remotion 코드를 복제·수정해 파생물을 팔거나 임대·재라이선스하지 않습니다(LICENSE.md, 해당 없음).
2. Remotion과 특별한 관계가 있거나 Remotion이 이 프로젝트를 승인한 것처럼 표기하지 않고, Remotion 이름을 홍보·판매에 쓰지 않습니다(v4.0 약관). 영상·README에 그런 표기 없음 — README는 사용 도구로만 언급합니다.
3. v4.0 약관과 LICENSE.md에는 영상 안 Remotion 출처 표기 의무가 없습니다.
4. 무료 자격은 LICENSE.md 기준 "개인"입니다. 전제가 바뀌면 아래 '다시 확인할 때'를 따릅니다.

## 다시 확인할 때

- 팀원이 늘어 영리 단체 총인원이 **4명 이상**이 되거나, 법인을 세워 그 법인 이름으로 영상을 만들 때
- 대학·공공기관 명의로 제작할 때(FAQ: 정부·교육기관은 사전 서면 허가 필요)
- Remotion 5.0으로 올릴 때(라이선스 일부 변경 예고). v5.0 약관에서 새로 생기는 항목을 그때 다시 확인합니다:
  - 관련 당사자 **총인원 4명 이상**이면 Company License(완성 영상만 받는 쪽은 제외)
  - 내보낸 Remotion 프로젝트 코드를 다른 사람이 내려받게 할 때 "Remotion으로 만들었음" 표시 (`video/` 공개 소스는 `package.json`·README에 Remotion을 이미 명시)
  - 코덱 특허(H.264·AAC 등)는 Remotion 라이선스에 포함되지 않음 — 방송·판매용 배포 시 별도 확인
