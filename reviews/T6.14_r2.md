## L-01 — 오류 종료 콜백에서 시작한 새 재생을 이전 오류가 취소한다

**위치:** `app/src/speech/guideTts.ts:223`~`:225`, `:135`의 finish.

오류 처리에서 `mine = current === run`을 저장한 뒤 `finish(run, 'error')`를 호출한다. finish는 current를 비우고 소비자의 onEnd를 동기로 실행한다. 이 onEnd에서 새 play를 시작하면 새 큐가 만들어지지만, 복귀 후 이전 mine 값으로 synth.cancel을 호출하므로 새 큐까지 지워진다. R1 판정의 “새 재생에 영향 없음”은 종료 콜백 안의 재진입에는 성립하지 않는다.

**직접 확인:** 실제 guideTts.ts를 TypeScript로 메모리에서 변환하여 실행했다. A/B의 onEnd(error) 안에서 NEW를 play하도록 하고 첫 발화에 synthesis-failed를 전달하니 결과는 `{"ends":["error"],"queue":[]}`였다. 새 요청이 큐에 남아야 하는데 없어졌다. 파일은 생성하지 않았다. cancel이 큐 전체를 제거한다는 동작은 [SpeechSynthesis.cancel 문서](https://developer.mozilla.org/en-US/docs/Web/API/SpeechSynthesis/cancel)와 같다.

현재 GuidePlayer의 onEnd는 상태만 바꾸며 직접 새 play를 호출하지 않으므로 일반 UI에서 즉시 재현되는 중간 우선순위 결함으로 올리지는 않는다. 오류 run의 콜백을 분리하고 자기 큐를 정리한 **뒤** 소비자에게 종료를 알리거나, 콜백 이후 새로운 재생 소유권을 보호하도록 순서를 정리하는 것이 좋다. 회귀 테스트는 오류 onEnd 안에서 새 play를 시작하여 새 큐·완료 콜백이 보존되는 경우를 포함해야 한다.

## L-02 — 재생 시 시작한 음성 탐색은 언어 변경 후에도 결과를 반영한다

**위치:** `app/src/ui/GuidePlayer.tsx:87`~`:93`.

마운트 effect의 init은 alive 플래그로 오래된 결과를 버리지만, 새 refreshVoice의 `engine.init(lang).then(setVoice)`에는 언어·요청 세대·언마운트 보호가 없다. 다음 순서에서 이전 언어의 결과가 현재 언어 상태를 덮어쓴다.

1. 음성 목록이 빈 상태에서 일본어 가이드를 재생하여 일본어 init이 대기한다.
2. 같은 컴포넌트를 유지한 채 중국어로 전환한다.
3. 중국어 음성만 로드된다. 중국어 effect는 ready로 끝난다.
4. 이전 일본어 탐색이 2초 뒤 no-voice로 끝나 setVoice를 실행한다.
5. 실제로 중국어 음성이 있는데 중국어 음성이 없다는 안내가 나타나며 다음 재생 전까지 유지된다.

이는 소스의 비동기 순서로 확인한 경합이며 이번 리뷰에서 실제 브라우저로 재현한 결과는 아니다. 일반 설정 경로는 화면을 이동해 GuidePlayer를 언마운트하므로 우선순위는 L이다. 그러나 열린 상태의 언어 변경은 컴포넌트 문서·테스트가 지원하는 계약이다. effect와 refreshVoice에 공통 언어/요청 세대 검사를 두고, 지연된 일본어 결과가 중국어 ready를 덮지 않는 테스트를 추가하는 편이 좋다. 현재 추가 테스트의 fakeTts는 ready/no-voice만 반환하고 null 및 지연 promise를 표현하지 않아 이 분기를 검사하지 않는다.

## 원고·다국어·기능·디자인 확인

- 코스 2개·장소 8곳에 EN/JA/ZH 원고가 있고 모든 원고에 미확인 예시 정보 고지가 있다. 메뉴·주문 순서·이동 거리·전시관 시간·시장 음식 설명은 앱 데이터와 대조했다. 이번 R2에서 새로 추가된 근거 없는 사실 단정은 발견하지 못했다.
- 일본어 예시 고지는 자연스럽게 개선됐고 중국어는 간체를 유지한다. Phrases / フレーズ / 短句 및 실패 안내의 Play / 再生 / 播放은 실제 탭·버튼 문구와 맞는다. 한글·통화 가격은 원고에 없다. 로마자 상호, 일본어 한자 고유명사, LED·App 등의 실제 낭독 발음은 음성별 차이가 있으므로 실기기 청취로 확인해야 한다.
- `T6.14.json`의 guide 객체를 en/ja/zh 적용 결과와 메모리에서 비교하여 세 언어 모두 완전 일치함을 확인했다.
- Next 변경은 알약·CSS·라디오 이름의 Next 표현 제거에 한정된다. nextStop 초기 목적지, 사용자가 고른 목적지, 네이버·Google 링크, 기존 testid·이벤트 기록은 유지한다. 기존 테스트 삭제는 Next 표시 기대 부분이며 행선지·저장 상태·데모 초기화 검증은 남아 있다.
- E2E의 주문·언어 변경 경로와 관련 소스를 확인했다. 새 버튼은 별도 testid를 사용하며 기존 한국어 듣기 기능과 주문 계약을 변경하지 않는다. E2E 81 통과는 작성자의 판정 보고이며 이번 직접 실행 결과는 아니다.
- Sheet의 dialog 이름·aria-modal·배경 inert·Tab 순환·Escape·초점 복귀를 재사용한다. 가이드 버튼은 44px 이상, 컨트롤은 50px이고 초점 외곽선·상태 aria-live·천천히 aria-pressed·문장 강조 밑줄이 있다. 색은 디자인 토큰을 사용하고 이모지는 없다. 원고 16px/1.65는 DESIGN 7장 예외 기준과 맞으며 reduced-motion에서 전환을 제거한다.
- 사진·출처·alt·사진 막과 확인 전 안내를 변경한 diff는 없다. 기존 배치에 가이드만 추가한 형태다. 새 텍스트 조합은 DESIGN의 파랑/흰색·tint 대비 기준을 따른다.
- 앱 변경은 T6.14 소유 파일과 guide 번역 적용 결과 범위다. 기준 문서 변경은 사용자 추가 요청 정의이며 기타 미추적 리뷰 파일·기존 tsbuildinfo를 이 작업의 범위 위반으로 추정하지 않았다.
