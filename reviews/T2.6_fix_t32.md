# T2.6 수정 — T3.2 측정 axe `label-content-name-mismatch` (문장 모음)

- 근거: `reviews/T3.2_metrics.md` — `/phrases`에서 3개 언어 모두 `label-content-name-mismatch`(WCAG 2.5.3 Label in Name, A)
- 원인: `screens/Phrases/index.tsx`의 연습 버튼(`.phr-row__main`)에 `aria-label="Practice: 덜 맵게 해 주세요"`를 붙여, 접근성 이름이 보이는 글자(문장·발음·뜻)로 시작하지 않고 보이는 글자 일부(발음·뜻)도 빠졌습니다.

## 수정 (`app/src/screens/Phrases/index.tsx`)
- 연습 버튼의 `aria-label` 제거 → 이름 = 버튼 안 보이는 글자 그대로(`문장 발음 · 뜻`), 보이는 글자로 시작.
- '연습' 동작 안내는 `aria-describedby`로 옮김: 화면 머리에 `hidden` span 하나(`useId`, 문구 `t('phrases.practice')`)를 두고 모든 연습 버튼이 참조. 3개 언어 문구는 사전 그대로.
- 보이는 화면·동작(누르면 `/practice` + `{src:'phrase', phraseId}`)은 바뀌지 않습니다.

## 회귀 테스트 (`Phrases.test.tsx`)
- 새 `describe('연습 버튼 접근성 이름 (WCAG 2.5.3 …)')` — en/ja/zh 각각 14개 버튼 모두:
  - `aria-label`·`aria-labelledby` 없음
  - 접근성 이름이 `^문장\s*발음 · 뜻$` (보이는 글자로 시작, 보이는 글자 전체를 순서대로 포함)
  - 접근성 설명 = 그 언어의 `phrases.practice`
- 기존 연습 이동 테스트는 이름 대신 `description: 'Practice'`로 버튼을 찾도록 갱신.
- 수정 전 코드에서는 `aria-label` 존재·이름 불일치로 실패하는 조건입니다.
