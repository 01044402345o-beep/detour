- 위치: `app/src/screens/Practice/practice.css:274`, `:314`; 상태 연결은 `app/src/screens/Practice/index.tsx:309` 부근.

- `DESIGN.md` 8장은 **“인트로 장면 외에는 자동 애니메이션 없음”**이라고 정한다. 기존에 있던 효과를 유지한 것이지만, 이번 T6.6의 새 디자인 체계 적용 완료 조건에는 맞지 않는다. reduced-motion에서 끄는 것은 구현되어 있으므로 그 옵션 자체의 누락은 아니다.
- 조치: 반복 파형·펄스를 제거하고 정적인 파란 파형/고리와 현재 상태 문구·정지 아이콘으로 녹음 상태를 전달한다. 누름 피드백과 상태 변경에 따른 짧은 전환은 유지할 수 있다. 녹음 중 움직임을 예외로 유지하려면 기준 문서의 명시적 예외가 필요하다.
- 확인: 기본 동작 설정에서 requesting/listening/processing 상태에 반복 애니메이션이 없는지, 녹음·취소·실패 안내 동작과 상태 전달은 유지되는지 확인한다.

### L-01 — 설정의 일본어 보조 문구에 끝 한 글자만 떨어지는 줄바꿈

- 작업 보고의 `settings-open-ja-360.png`에서 사진 출처 보조 문구 마지막 `ス`가 혼자 다음 줄에 남는다. `credits-ja-360.png`에서도 라이선스 설명 끝 `す。`만 다음 줄에 남는다.

- 조치: 설정의 해당 안내 문구에 균형 줄바꿈·엄격한 줄바꿈을 적용하고 360px EN/JA/ZH에서 다시 확인한다. 인용한 스크린샷은 과거 촬영본이지만 해당 문구와 CSS는 현재 코드에도 남아 있다.

### L-02 — Report의 ‘색만 변경’ 소유 제한을 넘은 글꼴 변경

- 위치: `app/src/screens/Report/Report.css:34`, `:67`, `:69`, `:103`, `:176`, `:215`.
- `task.md` T6.6은 Report를 “색만 새 토큰으로” 제한한다. 실제 diff에는 제목·구역 제목의 굵기 변경, KPI의 글꼴·굵기 변경, 순위 숫자의 글꼴 변경도 포함되어 있다. 작업 보고에 공개되어 있고 시각적으로 새 체계와 어울리지만, 명시된 소유 제한과는 다르다.
- 조치: Report의 비색상 변경을 분리/되돌리거나 coordinator가 디자인 글꼴 정리까지 허용하는 범위 예외를 기록한다. 한국어 고정 문구, 데이터, 데스크톱 배치와 기능은 그대로다.

## 요구 사항·회귀·테스트 검토

- 밝은 바탕·흰 목록·파란 주 버튼·선 구분·고정폭 진행/점수 숫자와 저장 방법 안내가 구현되어 있다. 문장 모음은 코스별/장소별 구조와 한국어→발음→뜻을 유지한다. T6.6 전용 시안은 없으므로 `c2-order.png`의 색·카드·버튼 체계와 문서 기준을 대조했다.
- Settings의 사진 출처 시트는 새 라우트 없이 PHOTOS 여섯 항목을 읽고 제목·저작자·연도·라이선스 링크·원본 링크·고지·변경 내용을 표시한다. 같은 장소 이름이 바로 옆에 있는 썸네일의 빈 alt와 lazy loading, 외부 링크의 noopener/noreferrer는 적절하다. 사진 위 글자는 없어 scrim 대비 규칙의 직접 적용 대상이 없다.
- 시연 도구는 기본 접힘이며 aria-expanded/aria-controls가 연결되어 있다. 리포트 진입·초기화 확인·언어 즉시 전환·정정 안내·연락처 조건부 표시는 유지된다. 저장된 장소의 확인 전/확인일 표시는 유지된다.
- 기존 이벤트 기록과 라우팅 핸들러, 마이크 사전 고지·실패 안내, 정상/느린 TTS, 저장·제보 동작은 대상 diff에서 삭제되지 않았다. 결과의 인식 일치도 설명·다시 하기·다음 문장·직원에게 보여주기도 유지되며 단어 일치 표시에는 체크/엑스와 낭독 문구가 함께 있다.
- 바뀐 테스트는 머리말·링 색·시연 도구 펼침 전제에 맞춘 갱신과 신규 요구 검증이다. 기존 동작 테스트 삭제는 없다. Result 테스트는 Git 기본 diff에서 binary로 표시되지만 `--text --ignore-space-at-eol`로 확인하면 실질 변경은 링 색 두 곳과 아이콘 검사 추가다.
- 사진 출처 열기·닫기·Esc·뒤로가기·초점 복귀 테스트가 통과한다. 다만 테스트 라우터가 MemoryRouter여서 브라우저 history와 실제 HashRouter 상호 작용 및 screen_view 중복 방지까지 독립적으로 입증하지는 못한다. 작업 보고의 실제 브라우저 확인은 참고 근거이며 이번 검토에서 같은 통합 조작을 재실행하지는 않았다.
- 기존 `data-testid`는 유지된다. `app/e2e/s5-lang-switch.spec.ts:68`은 접힌 상태의 `open-report`를 바로 누르므로 현재 코드와 맞지 않는다. 사전 고지된 T6.7 이관 사항으로 별도 결함 집계하지 않았다. T6.7에서 `demo-tools` 펼침 단계를 먼저 넣고 실행해야 한다.
- 패치의 세 언어 구조와 적용 번역, 의도된 override 세 개를 확인했다. 대문자/이모지 제거 외 문구 의미 손상이나 새 누락 키는 발견하지 못했고 i18n 검사가 통과했다.
- 사용한 주요 글자/배경은 blue/white, blue/tint, mute/ground, danger/white 등 기준 대비를 충족하는 토큰 조합이다. 버튼·링크의 44px 최소 크기, 3px 초점선, Sheet의 배경 잠금·초점 순환/복귀, 전역 reduced-motion 차단을 코드로 확인했다. 모든 실제 픽셀 대비와 키보드 조작을 브라우저에서 측정한 결과는 아니다.
