## 직접 재검증 결과

### QR 내용·파일 무결성

- 생성 보고서의 jsQR와 다른 구현인 **`@zxing/library@0.21.3` QRCodeReader**를 사용했다. 패키지는 unpkg에서 메모리로 읽었으며 의존성 설치·파일 저장·QR 업로드 없이 로컬에서 디코드했다.
- PNG는 실제 파일의 IHDR/IDAT를 읽고 Node 내장 zlib로 압축 해제한 뒤 PNG 필터를 복원하여 ZXing에 전달했다. 결과는 정확히 `https://01044402345o-beep.github.io/detour/`이며 끝 `/`까지 일치한다.
- SVG는 실제 stroke path의 M/m/h 명령을 37×37 격자로 복원하여 래스터화했다. 148·296·345·461·540·648·1024px에서 ZXing 디코드가 모두 같은 URL과 일치했다. SVG 검사는 브라우저 화면 캡처 디코드가 아니라 path 기반 재구성 검사다.
- PNG: 1024×1024, 8-bit RGBA, 색은 불투명 `#151a26`·`#ffffff` 두 개뿐이다. PNG 청크는 IHDR·IDAT·IDAT·IEND이며 별도 텍스트·촬영 위치 메타데이터가 없다.
- SHA-256은 기존 보고서와 일치한다.
  - PNG: `45cdd9ca77748ad24d410d254e48c6d80ef7e182d5ee88d9e2baed0592fbbae6`
  - SVG: `83fef49b1a17038f8234136cc21de89cc9d0a11fc8538a6004e8e64ef5b8f8b8`

### 크기·여백·대비와 현장 검증의 한계

- SVG는 29×29 데이터 영역 주위에 4모듈 흰 여백을 보존한다. PNG의 어두운 픽셀 범위는 x/y 모두 111~913으로, 양 끝 흰 여백은 111/110px이다. QR 위 로고·장식·투명 배경은 없다.
- 전경/배경 상대 휘도 대비는 약 **17.39:1**이다. 슬라이드의 흰 카드와 추가 padding도 QR 내부 여백을 침범하지 않는다.
- Orca 내장 브라우저에서 로컬 HTML을 실제로 열어 이미지 로딩과 DOM 배치를 확인했다. 1920×1080에서는 QR 648×648px, 1024×768에서는 약 345.6×345.6px이며 둘 다 화면 안에 온전히 들어온다. 후자는 슬라이드가 y=96~672에 배치된다. 원본 1600×900 기준 QR은 540px로 화면 너비의 33.75%다.
- 파일 해상도·대비·여백에는 발견된 결함이 없다. 다만 디지털 디코드 성공은 인쇄 품질·촬영 거리·프로젝터 밝기·반사·휴대폰 자동초점의 실측을 대신하지 않는다. 인쇄는 QR 원본을 흰 여백 포함해 사용하고, 발표장에서는 실제 투사 크기와 가장 먼 사용 좌석에서 확인해야 한다. HTML에 별도 인쇄 CSS는 없으므로 HTML 직접 인쇄 결과의 온전한 배치는 미검증이다.
- 이 현장 스캔은 task.md 0.3절 3-f에 따라 배포 후 남겨 두는 검증이며, 미수행 자체를 배포 전 결함으로 세지 않았다.

### 문구·개인정보·외부 리소스·공개 적합성

- 표시 문구는 시연임을 밝히고 PRD의 원도심 동선·주문 카드·현장 한국어 범위와 일치한다. 제휴·공식 주문·결제·가격 확정·실제 통계·발음 정확도를 주장하지 않는다. 가게별 정보나 리포트 수치를 보여주지 않아 이 슬라이드에 비제휴·예시 데이터 문구가 없다는 이유만으로 PRD 위반으로 보지 않는다.
- QR에는 지정된 공개 URL만 있다. 숫자가 포함된 GitHub 계정명도 요청된 배포 주소 그대로이며 추가 연락처·사용자 식별 토큰을 넣지 않았다.
- HTML의 유일한 이미지 참조는 `../app/public/qr.svg`다. 외부 스크립트·폰트 다운로드·분석 SDK·폼·저장소 접근·네트워크 전송 코드는 없고, 인라인 JS는 화면 비율 조정만 수행한다. SVG는 경로 도형만 포함한다. URL 텍스트를 표시하는 것 자체가 해당 사이트로 요청을 보내지는 않는다.
- 실사 사진·가게 로고·개인 서류·인증정보가 없으므로 검토 대상 내용은 공개 저장소에 적합하다. 이는 대상 네 파일에 대한 판단이며 저장소 전체나 git 이력의 민감정보 감사는 아니다. QR 상대 경로 때문에 슬라이드만 단독 복사하면 이미지가 누락되므로 현재 디렉터리 구조를 함께 보존해야 한다.
- 기존 보고서는 배포 후 실제 스캔을 남은 작업으로 명확히 분리한다. 앱 전체 테스트 통과 기록은 이번 QR 검토에서 재실행하지 않았으며, 현재 병렬 변경까지 검증했다는 뜻으로 확장하지 않는다.
