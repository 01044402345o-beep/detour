## 1. 실행 방법

1. `cd app && npm run build` → `npx vite preview --port 4190 --strictPort`(base `/edulleo/`는 vite 설정에 들어 있음) → `http://localhost:4190/edulleo/`

3. 스크립트
   - `$T/shots.mjs <lang> <width>`: 검증표 화면 30개 촬영 + 자동 판정. 6개 조합(EN/JA/ZH × 360×780·430×932)

   - `$T/offline.mjs`: 오프라인 새로고침, 글꼴 차단
   - `$T/detectcdp.mjs`: Edge를 `--remote-debugging-port=9334`로 띄워 화면마다 `impeccable detect --json --cdp 9334 --target localhost:4190` (390×844)
4. 자동 판정 방법
   - 가로 넘침: `documentElement.scrollWidth - clientWidth`와 화면 오른쪽 밖으로 나간 요소(가로 스크롤 영역 안 요소 제외)
   - 고정 요소 가림: 스크롤 영역(`.app-view`, 시트는 `[role=dialog]`)을 끝까지 내린 뒤, `fixed`/`sticky(bottom)` 요소 위 끝과 그 밖 내용(글자·이미지·버튼·링크)의 가장 아래 끝을 비교. 내용이 스크롤 영역 아래로 빠져 닿지 않는 경우도 따로 셈
   - 끝 글자 한 개 줄: 블록마다 글자 하나씩 `Range.getClientRects()`로 줄을 나눠, 2줄 이상이고 마지막 줄의 문장부호 뺀 글자가 1개 이하인 경우(한자·가나·한글 포함 줄)
   - 잘림: `overflow hidden/clip` 상태에서 내용이 넘치는 글자 요소(`sr-only` 제외)
   - 글꼴: CDP `CSS.getPlatformFontsForNode`로 실제로 그려진 시스템 글꼴 이름·글자 수
   - 콘솔 오류: `console.error`·`pageerror`를 화면별로 수집
