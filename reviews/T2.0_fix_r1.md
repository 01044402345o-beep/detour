## M01 (Low, 필수) — Sheet 포커스 트랩
- `ui/overlay.ts`:
  - `lockBackground()`: `#app-overlay`의 형제(main.app-view·탭바)에 `inert` 설정, 토스트 알림 영역(`role=status`)은 제외(시트 중에도 토스트 낭독). 모듈 단위 카운터 — 마지막 시트가 닫힐 때만 원래 값으로 복원. `#app-overlay`가 없으면 아무것도 안 함.

- `ui/Sheet.tsx`: 열린 시트 스택을 두어 **맨 위 시트만** Esc·Tab 처리(겹친 시트에서 Esc 한 번에 모두 닫히던 문제도 함께 해소). cleanup 순서: keydown 해제 → 스택 제거 → inert 해제 → 이전 포커스 복귀.
- 테스트(`ui/components.test.tsx`): inert 설정·해제와 포커스 복귀, 토스트 영역 제외, 두 시트 겹침 시 inert 유지·Esc는 맨 위만, Tab/Shift+Tab 순환(비활성 버튼 건너뜀, 중간 요소는 기본 동작), 포커스 가능 요소 없을 때 컨테이너 유지.

## L01 — dialog 이름 판별 유니온
- `SheetProps = SheetBase & ({ title: Exclude<ReactNode, undefined|null|boolean>; label?: undefined } | { title?: undefined; label: string })`.
- title 없으면 `<h2>` 대신 빈 자리만 두고 `aria-label={label}`.
- 테스트: title → `getByRole('dialog', { name: title })`(기존), label → `{ name: label }` + heading 없음, 이름 없는 `<Sheet open onClose />`는 `// @ts-expect-error`로 타입 오류 확인(typecheck 통과 = 오류 발생 확인).

## L02 — 빈 phraseId
- `router/navState.ts`: `PhraseInputState = { src: 'order' } | { src: 'phrase'; phraseId: string }`. `phraseInput`은 src·ID를 그대로 둠(`phraseInput('phrase','')` → `{ src:'phrase', phraseId:'' }`).
- `parsePhraseInput`: phrase는 `isValidId(phraseId)`(domain/events.ts, 이용 기록 ID 형식)일 때만 통과.
- 테스트: `parsePhraseInput(phraseInput('phrase',''))` → null, `'SSD-1'`·한글 문장·숫자 → null, `'ssd-1'` → 그대로.

## 사용 안내 (`reviews/T2.0_usage.md`) 갱신
- 화면 루트 `data-testid="screen-<key>"` 권장 → **필수**(E2E 사용).

- `:id`만 바뀌는 화면은 콘텐츠 루트에 `key={id}` (판정 nit).
- 연습·직원 입력: 새 타입, 검증은 parsePhraseInput 한 곳, null 처리 범위, 데이터 존재 확인은 받는 화면, "state 없음 = 새로고침" 가정 금지.
- Sheet: title 또는 label 필수, 배경 inert 자동(화면이 inert 직접 걸지 말 것), Esc는 맨 위 시트만, Tab 순환.
