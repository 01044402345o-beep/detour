## M-01 — 일시정지 후에도 주문 장면의 파형이 무한 반복됨

- 위치: `app/src/screens/Lang/lang.css:478`, `app/src/screens/Lang/index.tsx:172`, `app/src/screens/Lang/index.tsx:201`, `app/src/screens/Lang/scenes.tsx:14`.
- 재현: reduced-motion이 꺼진 상태에서 Order 탭을 선택하고 약 2.1초 기다린다. 버튼 이름은 이미 `Play scenes`인데 카드의 네 파형 막대가 계속 움직인다. 자동으로 주문 장면에 진입한 뒤 일시정지를 눌러도 동일하다.
- 근거: 버튼은 `playing`만 바꾸고 장면 전환 타이머만 제거한다. 자식 장면은 `active`·`reduce`만 받으며, `.lo-card.is-on .lo-w i`의 `lang-wave 900ms ... infinite`에는 정지 상태 조건이 없다. 장면 내부 단계 타이머 역시 정지 상태를 받지 않는다. 무한 파형은 잠깐 끝나는 전환 효과와 달리 사용자가 화면을 떠나거나 OS 설정을 바꾸기 전까지 멈출 수 없다.
- 영향: PRD 7장 및 DESIGN 7·9장의 자동으로 바뀌는 인트로 내용을 멈출 수 있어야 한다는 요구를 온전히 만족하지 않는다. 버튼 이름 전환 자체는 문제없지만, 전달하는 정지 상태와 실제 움직임이 불일치한다.
- 수정 제안: 정지 상태에서 최소한 반복 애니메이션을 멈추거나 정적 최종 모습으로 바꾼다. 장면 내부 움직임에도 명시적인 재생 상태를 전달해 정지 정책을 일관되게 적용한다.
- 검증 보강: 현재 재생/정지 테스트는 `data-scene`이 유지되는지만 검사한다. 주문 장면에서 정지 후 반복 애니메이션이 멈추는지 브라우저의 animation play state 또는 동등한 검증을 추가한다.

## M-02 — 주문 그림 수량·기호의 대비가 4.5:1 미만이며 앰버를 글자색으로 사용함

- 위치: `app/src/screens/Lang/lang.css:329` 부근의 `.lo-row`, `app/src/screens/Lang/lang.css:388` 및 `:395`의 `.lo-step b`·`.lo-n`.
- 재현: Order 장면에서 수량이 1·2가 된 모습을 확인한다. 해당 숫자는 `--signal`, 0은 `--tint`, +/− 기호는 흰색이다.
- 근거: 파란 바탕 `#1D5BD6` 위에 stage의 흰색 7%, row의 흰색 14%가 순차 합성되어 행 배경은 대략 RGB(74,124,222)가 된다. 소스의 합성값으로 상대 휘도를 계산한 대비는 **앰버 숫자 2.23:1, tint 숫자 3.44:1, 흰 기호 4.02:1**이다. 정적 작업 스크린샷 `360-en-order.png`에서도 동일한 색 구성을 확인했다.
- 영향: PRD 7장·DESIGN 9장의 글자 대비 4.5:1, DESIGN 2장의 signal 글자색 금지를 위반한다. `aria-hidden`인 설명 그림이어도 시각적으로 제시된 숫자의 대비가 개선되지는 않는다. 시안에 같은 앰버 숫자가 있지만 문서가 시안보다 우선한다.
- 수정 제안: 수량과 기호를 대비가 확보되는 색으로 바꾸고, 필요하면 행 배경을 어둡게 조정한다. 흰색으로만 바꾸면 현재 배경에서 4.02:1이므로 배경도 함께 검토해야 한다. 앰버는 허용된 진행 표시·강조 밑줄 등에 한정한다.
- 검증 보강: 실제 합성 배경에 대해 0·양수·+/−를 각각 검사한다. 기존 공용 토큰 대비 검사만으로는 반투명 행 배경의 대비를 보장하지 못한다.

## 정상 확인 및 범위

- 로고 → 파란 안내판 → 제목·필요성 → 언어 선택·발음 안내 → 시작 버튼 구성이 시안의 의도를 따른다. 세 장면·4.4초 전환·수동 탭 선택 시 전환 중지·재생 버튼·초기 reduced-motion 정적 상태·언마운트 시 타이머 정리가 구현되어 있고 단위 테스트가 통과했다.
- 버튼 이름을 Play/Pause로 전환하는 방식은 상태 전달 수단으로 타당하다. 자동 재생 중 설명의 `aria-live=off`, 정지 후 `polite`도 수용 가능하다.
- 언어 선택 네이티브 radio, 즉시 저장·즉시 문구 변경, 기본 EN 저장, `/lang`, `screen-lang`, `lang-en|ja|zh`, 시작 버튼 `lang.start`, 발음 안내 및 라우터의 screen_view 1회 계약을 유지했다. `app/e2e/support.ts`의 `chooseLanguage`가 쓰는 label testid와 버튼 접근 가능한 이름도 그대로다. 실제 E2E는 이번 검토에서 실행하지 않았다.
- 기존 테스트 10개를 삭제하지 않았고 버튼 개수 기대만 1→2로 바꿨다. 새 테스트 9개는 장면·타이머·키보드·언어 전환 등 변경 동작을 다룬다. 단, M-01의 반복 움직임 정지는 검증하지 않는다.
- T6.1 번역 패치의 EN/JA/ZH 42개 leaf 값을 적용 사전과 읽기 전용 비교하여 모두 일치함을 확인했다. 누락 키를 찾지 못했다. `简体中文` 유지와 중국어 전각 구두점 override는 의미 회귀가 아니다.
- 주요 텍스트는 새 색·글꼴·굵기 체계를 사용한다. 탭·재생·언어 선택의 실제 동작 영역은 44px 이상이며, 언어 선택에는 파란 초점선, 파란 안내판 내부에는 대비 확보를 위한 흰 초점선이 있다. 후자는 DESIGN의 파란 초점선 문구와 색이 다르지만 시인성을 위한 합리적 처리로 보았다.
- 사진을 쓰지 않으므로 사진 출처·막·사진 alt는 해당 없음. 장식 그림은 aria-hidden이고 장면 설명이 따로 있다. 실제 장소·가격·알레르기 정보를 표시하는 화면이 아니어서 확인 전 안내 정책이 새로 필요한 부분은 없다.
- 작업 보고의 수정 파일 목록은 T6.1 소유 범위와 일치한다. 공용 사전의 패치 적용은 Phase 6에서 허용된 예외다. 공유 작업 트리의 다른 변경을 T6.1이 했다고 판단할 증거는 없으며, 작성자별 변경 귀속은 현재 diff만으로 확정할 수 없다.
