## 동작·계약
- 입력: `parsePhraseInput(location.state)`. state 없음·형식 오류·데이터에 없는 문장 ID → 현재 주문으로 대신. 주문도 비면 빈 주문 안내 + "Course" 버튼(응답 버튼·기록 없음)
- 이벤트: `staff_shown`(src, 실제 placeId, phrase면 phraseId) location.key당 1회 · 읽어주기 `phrase_play`. false면 DEV 경고. screen_view는 기록하지 않음
- 응답 버튼 → `navigate(PATHS.reply, { state: { reply, input } })`. 응답 state가 틀리면 /staff로 replace
- 품절 → `navigate(placePath(id), { state: { tab: 'menu' } })`. id는 order면 currentPlaceId, phrase면 그 문장의 장소. 장소가 `orderable:false`(메뉴 탭 없음)거나 없으면 버튼 숨김. **T2.3 Place 화면이 `state.tab`을 읽는지는 확인 필요**(주문 가능한 장소는 기본이 메뉴 탭이라 읽지 않아도 메뉴 탭으로 열림)
