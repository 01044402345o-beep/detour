# T0.3 수정 r1 — favicon 404 해소

- 일자: 2026-11-23
- 원인: 첫 배포 smoke에서 콘솔 오류 1건. `index.html`에 아이콘 링크가 없어 브라우저가 `/detour/favicon.ico`를 자동 요청했고 404가 났음.

## 변경
| 파일 | 내용 |
|---|---|
| `app/public/favicon.svg` (신규) | 목업 'D' 로고. 64×64 viewBox, 둥근 사각형(rx 19, 목업 11/38 비율), 135° 그라디언트 `#f58a5c`→`#c24e22`, 흰 D는 글꼴에 의존하지 않도록 path로 그림 |
| `app/index.html` | `<head>`에 `<link rel="icon" type="image/svg+xml" href="%BASE_URL%favicon.svg" />` 한 줄 추가 |

`app/src` 등 다른 파일은 건드리지 않았습니다.

## 확인
- `npm run build` 성공. `dist/favicon.svg`가 생성됨.
- `dist/index.html`의 링크가 `href="/detour/favicon.svg"`로 바뀜(base `/detour/` 적용).
- `vite preview` 대상:
  - `GET /detour/favicon.svg` → 200, `image/svg+xml`
  - Playwright(시스템 Edge)로 `/detour/` 로드: 콘솔 오류 0건, 4xx 응답 0건, favicon 요청은 `/detour/favicon.svg`만 있고 `favicon.ico` 요청 없음
- 96px·16px로 렌더해 눈으로 확인: 그라디언트와 흰 D가 정상, 16px에서도 D가 읽힘.
