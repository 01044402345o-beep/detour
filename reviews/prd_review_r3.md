## 1. M-6 해소 여부와 심각도

**M-6은 해소됐다.** R2 판정의 세 가지 닫힘 조건이 모두 현재 원문에 반영돼 있다.

| 확인 위치 | 현재 요구사항 | 판단 |
|---|---|---|
| F-04, 127행 | 개별 미확인 가격은 '가격 확인 필요', 합계는 F-05 규칙을 따름 | 미확인 가격을 제외한 부분 금액을 전체 합계처럼 보이게 하던 독립 규칙이 제거됨 |
| F-05, 128행 | 담은 항목에 가격 미확인이 하나라도 있으면 '총액 확인 필요', 모든 가격이 확인된 경우에만 합계 예시가 표시 | 혼합 주문과 전부 미확인 주문 모두 금액 대신 안내가 표시되므로 기존 반례가 해소됨 |
| 8.1절 MenuItem, 201행 | `priceKrw?: number /* 없으면 가격 미확인 */` | 메뉴 전체의 `verified`와 별도로 가격 미확인 상태를 표현할 수 있음 |

**심각도를 Medium에서 Low로 낮춘 판정에 동의한다.** R2 지적 당시에도 부분 합계의 오해 가능성은 있었지만, 이 문서의 대상은 심사 시연용 데모이고 온라인 결제·실제 주문 전송은 범위 밖이다(65행). 금액은 예시가로 표시되고 실제 결제는 현장에서 이루어지는 전제이므로, 남아 있던 가격 표시 공백을 Low로 분류하는 것이 타당하다. 이 동의는 가격 부분에 한정하며, 앞서 해소된 알레르기·영업 상태까지 일괄 하향하는 뜻은 아니다. 수정까지 완료됐으므로 현재 미해결 Low에도 집계하지 않는다.

## 2. v0.3 변경 5줄의 신규 문제 확인

수정 보고서와 현재 원문을 대조해 아래 5줄 및 연결된 요구사항의 정합성을 확인했다.

| 위치 | 변경 내용 | 신규 문제 판단 |
|---|---|---|
| 5행 | 버전 v0.3 | 변경 이력의 버전·날짜와 일치 |
| 127행 | F-04가 F-05의 합계 정책 참조 | 개별 가격 안내와 합계 안내의 역할이 구분되고 충돌 없음 |
| 128행 | 미확인 가격 포함 시 총액 안내로 대체 | 같은 행 앞부분의 '합계 예시가'에 적용되는 조건을 명시한 것으로 읽히며 모순 없음 |
| 201행 | 가격을 선택 필드로 변경하고 미확인 의미 부여 | F-04·F-05의 상태 표현을 보완함. 메뉴명·수량·단위로 문장을 만드는 F-06에는 가격 필수 조건이 없어 주문 카드 생성과 충돌 없음 |
| 258행 | v0.3 변경 이력 추가 | M-6 반영 내용과 현재 본문이 일치 |

가격이 모두 확인된 주문은 기존 합계 예시가, 일부 또는 전부 미확인인 주문은 '총액 확인 필요'가 된다. 미확인 메뉴를 담지 않았거나 제거한 경우에는 '담은 항목'만을 기준으로 판단할 수 있다. 새 안내 문구의 번역은 기존 1.3절의 모든 사용자 문구 3개 언어 전환 요구(32행)에 포함된다. 이 변경에 별도 신규 지적은 없다.

7행 범위 표기는 R2 검토·판정에서 이미 확인했던 상태이며, 수정 보고서도 이번에는 변경 이력에만 기록했다고 설명한다. 따라서 이를 이번 본문 변경 5줄에 추가하지 않는다. 현재 범위 표현은 3.2절의 이후 확장 권역 제외와 일치하며 새 충돌은 없다.
