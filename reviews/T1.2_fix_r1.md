## M-1 — S13 운영자 리포트 한국어 고정 (반영)

- **신규 `operatorKo.ts`:** `OPERATOR_KO` 상수(목업 S13 `:680` 이하 문구 기준, 기존 `operator.*` 29키와 1:1 + 목업의 `+{count} 방금 제보됨`을 `kpiReportsJustNow`로 추가)와 `formatKo()`.
  - 머리 주석에 "S13 운영자 리포트는 한국어 고정(coordinator 결정, 2026-11-23). 언어 전환과 무관"을 적었습니다.
  - 자리표시자(`{period}`·`{pct}`·`{count}`·`{h}`)는 템플릿 문자열 한 가지 방식으로 통일했습니다. `formatKo(key, params)`는 판정 지침의 `formatKo(template, params)` 대신 **키**를 받습니다. 이유는 두 가지입니다: 키 타입(`OperatorKoKey`)으로 오타를 막고, 경고 메시지에 키 이름(`OPERATOR_KO.deviceEvents`)이 남습니다. 누락 경고 규칙은 t()와 같은 `fillTemplate`(신규 `format.ts`)을 씁니다.
  - 장소명은 상수에 중복 정의하지 않았습니다. 코스 밖 항목(`중앙시장 (코스 외)`·`바로 귀가 (대전역)`)만 두었습니다.
- **세 사전에서 `operator` 객체 삭제.** 관광객 UI의 진입 버튼 `settings.operatorReport`는 다국어로 유지했습니다.
- **`hardcodeCheck.ts`:** `ALLOWED_LITERALS`에 `flattenStrings(OPERATOR_KO)` 추가. 경로 예외는 추가하지 않았습니다.
- **테스트 (`operatorKo.test.ts` 신규, `index.test.ts`):** (a) OPERATOR_KO 모든 값이 비어 있지 않은 한국어, (b) `<h1>{OPERATOR_KO.title}</h1>` 통과·`<h1>운영자 리포트</h1>` 위반, (c) 세 사전에 `operator` 키 없음. `operator.sampleBadge` 필수 키 검사는 `OPERATOR_KO.sampleBadge` 검사로 옮겼습니다. formatKo 치환·누락 경고 테스트도 추가했습니다.

## M-2 — 하드코딩 검사 보강 (부분 타당 범위대로 반영)

1. **`value` 속성:** `button`·`option`, `input[type=submit|button|reset]`일 때만 보이는 속성으로 봅니다(`isVisibleValue`). 그 밖의 `value`(폼 상태값)는 제외하되, 문장형이면 2번 규칙으로 잡힙니다.
2. **문장형 라틴 규칙(`isLatinSentence`):** 검사 대상 파일의 모든 위치(변수 초기값·배열 요소·함수 인자·객체 값)에 적용합니다.
   - `^[A-Z][a-z'’]+(?:\s[A-Za-z'’]+)+[.!?…]?$`, 또는 라틴 문자·공백을 포함하고 `. ! ?`로 끝나는 문자열.
   - 템플릿 문자열은 **전체**를 기준으로 판단합니다(`` `Saved ${n} items.` `` → `Saved x items.`). 조각 단위로 판단하면 `Saved`·`items.`가 각각 한 단어라 빠지기 때문입니다.
   - 예외: `ALLOWED_LITERALS`(브랜드 포함), `console.*(...)`·`…Error(...)` 인자, 타입·import 위치.
   - 한 단어(`'Open'`)와 소문자·하이픈 식별자는 잡지 않습니다. 이 경로는 Phase 2 E2E 5가 맡는다고 규칙 주석에 적었습니다.
   - 공백 문자는 `\s`를 씁니다. `[  ]`로 쓰면 prettier가 리터럴 NBSP로 바꾸고 ESLint `no-irregular-whitespace`에 걸렸기 때문입니다.
3. **검사 범위:** `isScanned`를 `src/` 아래 모든 `.ts`·`.tsx`(EXEMPT_PATHS 제외)로 넓혔습니다. 예외 경로(i18n·data·domain·테스트·test 설정)는 판정대로 유지했습니다. 확장 후 저장소 전체 검사(현재 `store/`·`speech/`·`App.tsx`·`main.tsx`·`types.ts` 포함)에서 위반 0건이라 옮긴 문자열은 없습니다.
4. **규칙 주석** 갱신(규칙 1~5 + E2E 5 이관 명시).
5. **회귀 테스트:** 반례 A(지역 변수 `'Show to staff'`)·B(`<input type='submit' value='Pay now'>`, button/option value) 위반. C(`['Open','Closed']`)는 테스트 이름에 "의도적으로 통과 — Phase 2 E2E 5가 맡음"으로 명시. `src/hooks/useToast.ts`의 `toast('저장했어요')`·`toast('Saved to your list.')` 위반. 객체 값·템플릿 문장 위반. 오탐 방지: `className='flex gap-2'`, `navigate('/place/ssd')`, `logEvent({ type: 'place_view' })`, `console.warn('Missing key x.')`, `new Error('Store is not ready.')`, `'Daejeon Detour'`, `'ko-KR'`, text input `value='ssd'` 통과. `isScanned('src/store/…')`·`src/hooks/…`·`src/speech/…`는 이제 검사 대상.

## L-1 — params 전체 생략 시 경고 (반영)

- 신규 `format.ts`의 `fillTemplate(template, params, label)`이 `params ?? {}`로 치환 루프를 항상 돕니다. 빠진 이름마다 개발 모드 경고를 내고 자리표시자는 그대로 둡니다(영어 fallback 없음 유지). `t()`와 `formatKo()`가 같이 씁니다.
- 키별 필수 params 타입 제한은 판정대로 도입하지 않았습니다.
- 테스트: `t('ja','menu.items')` → `{count}点`, `console.warn` 1회. 자리표시자 없는 키(`nav.saved`)를 params 없이 부르면 경고 없음.
