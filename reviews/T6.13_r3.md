# T6.13 코드 검토 R3

검토일: 2026-11-26. 판정: **승인 — H 0 / M 0 / L 0, 새로 발견한 수정 필요 항목 없음**.

## R2 조치 및 R1 유지 확인

- **R2 M-01 해결.** `app/src/screens/Course/walkPick.ts`는 존재하지 않는다. `useAppStore.ts:267`의 `walkPicks`와 `setWalkPick`이 코스별 선택을 보관하고, `:330`의 `resetData`가 이를 빈 객체로 초기화한다. 실제 설정 확인 동작(`Settings/index.tsx:191–195`)도 이 `resetData`를 호출하므로, 테스트 전용 초기화에만 연결되어 있던 문제가 해소됐다.
- `Course/index.tsx:143`에서 store의 해당 코스 선택을 구독한다. 상세 왕복에서는 유지되고, 선택하지 않았거나 유효하지 않은 정류장 ID이면 기존 `nextStopIndex` 결과를 사용한다. 다른 코스 선택을 덮어쓰지 않는 객체 병합이며, 초기화 후에는 다음 정류장·두 지도 주소·버튼 문구가 다시 1번을 따른다.
- store의 `partialize`에 `walkPicks`를 추가하지 않았고, 초기값은 `{}`다. 따라서 상세 왕복 보존을 위해 브라우저 영구 저장 범위를 넓히지 않았다. 기존 주문·저장·제보·이벤트 저장 및 복원 정책도 변경하지 않았다.
- **R1 M-01 유지 해결:** 두 코스 각각 3번 선택 → 화면 제거 → 3번 `place_view` → 재마운트 후 선택·네이버·Google은 3번, Next는 4번인 테스트가 유지되고 통과했다.
- **R1 L-01·L-02 유지 해결:** Next 배지는 11.5px/16px이며 일본어 질문은 패치와 적용 파일 모두 `どこまで歩きますか？`다.
- **R1 L-03:** 전체 정류장 이름·순번·Next를 포함한 접근성 이름 테스트가 유지된다. 이전 판정에 실제 Edge 화살표·Tab·초점·상세 왕복 확인 및 E2E 81 통과가 기록되어 있다. 이번 검토에서는 그 브라우저 조작과 E2E를 독립 재실행하지 않았다.

## 기준·기능·접근성 검토

- `task.md` Phase 6 머리 규칙과 T6.13 완료 조건, DESIGN.md v1.1, PRD의 F-03·S02와 v0.12 추가 요청을 대조했다. 2×2 선택, 초기 다음 정류장 선택, 선택과 Next의 분리, 두 코스의 목적지·문구·안내 변경이 구현됐다. 사용자 추가 요청으로 문서화된 기능 변경이다.
- 네이티브 radio의 동일한 코스별 name, fieldset/legend, 전체 이름 aria-label을 유지한다. input은 화면에서만 숨기며 키보드 초점 대상이다. 선택 칸은 최소 44px, 초점은 `:has(input:focus-visible)`의 3px 외곽선이다. 별도 키 이벤트로 브라우저의 화살표 동작을 방해하지 않는다.
- 선택은 파란 테두리·번호 채움, 다음 정류장은 글자가 있는 앰버 배지로 구별된다. ink/mute/blue/tint 조합은 DESIGN의 4.5:1 이상 글자 대비 체계를 따르고 앰버 위에는 ink를 쓴다. 전역 reduced-motion 규칙이 새 transition에도 적용된다.
- 선택 클릭은 방문 이벤트를 생성하지 않는다. 핀·목록의 상세 이동 및 상세 화면의 기존 이벤트 기록 경로, `screen-course`, `stop-<id>`, `start-walking`, `google-maps` 계약을 유지한다. `app/e2e/support.ts:101–108`의 코스 진입·정류장 클릭 경로와도 충돌하지 않는다.
- 사진·빈 alt·사진 출처·음식 예시 안내·확인 전 요약/혼합 표시 로직에는 변경이 없다. 새 사진이나 사진 위 막을 추가하지 않았다.
- EN/JA/ZH의 새 3개 키는 패치 원본과 적용 결과가 일치한다. JA 전각 물음표·「」, ZH 전각 물음표·“”는 적절하며 누락 키나 의미 차이를 발견하지 않았다. 선택 칸의 말줄임은 명시된 디자인이고 전체 이름은 아래 안내 및 접근성 이름에 제공한다.
- T6.13 소유 목록에 store와 store 테스트가 명시되어 있다. 현재 관련 diff는 화면·store·번역 패치 및 적용 파일·해당 문서 범위이며, 무관한 코드 변경을 발견하지 않았다. 공유 번역 파일의 실제 작성 주체는 diff만으로 판정할 수 없다.

## 테스트 품질

기존 테스트 삭제는 없다. 안내 변경에 따른 기대값 3곳만 `dirNext`에서 `dirTo`로 갱신했고, 선택·복귀·접근성 이름·초기화 검사를 추가했다. R2 추가 Course 테스트는 두 코스에 선택을 남긴 뒤 실제 store action `resetData()`를 실행하여 빈 선택과 1번 radio·Next·네이버/Google 주소·시작 문구를 검증한다. store 테스트도 초기화 및 localStorage 저장분에 `walkPicks`가 없음을 검사한다. 상세 왕복 테스트는 실제 라우터 이동 대신 언마운트/이벤트 갱신/재마운트로 상태 수명을 검사한다는 한계가 있으나 이번 수정의 회귀 지점을 직접 다룬다.
