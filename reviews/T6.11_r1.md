## 지적 사항

### L-01 — T6.11 삽입 위치 때문에 T6.10 완료 조건이 T6.11에 붙음

- 위치: `task.md:452–455`.
- T6.11 항목을 T6.10 제목과 하위 항목 사이에 넣어, 직접 촬영 사진 두 장·행인 흐림·사진 저작자 표시라는 T6.10 요구가 T6.11의 하위 요구처럼 읽힌다. T6.11 자체 완료 조건도 별도로 구분되지 않는다.
- 수정 권고: 기존 T6.10 하위 항목 뒤로 T6.11을 옮기고, 사진 가독성·두 시작 버튼·360px 세 언어 확인이라는 실제 완료 조건을 명시한다. task.md는 선언된 화면 소유 범위 밖의 변경이지만 작업 등록용 문서 수정으로 보이며, 애플리케이션의 무관한 파일 변경은 없다.

### L-02 — 새 시작 버튼 테스트가 ‘한 번만 이동’을 검증하지 않음

- 위치: `app/src/screens/Home/Home.test.tsx:126–135`.
- 새 테스트는 이름에 ‘한 번만 이동’을 적었지만 최종 URL과 화면 존재만 확인한다. 부모 article까지 이벤트가 전파되어 같은 URL로 두 번 navigate하더라도 이 검증은 통과할 수 있다. 기존 원도심 테스트에는 screen_view 검증이 있으나 새 시장 버튼에는 없다.
- 수정 권고: 시장 버튼 클릭의 navigate 호출 횟수 또는 라우터 이력 증가 횟수를 확인하고, screen_view가 home → course로 한 번 기록되는 것도 확인한다. 버튼 내부 SVG 클릭도 부모 분기까지 함께 검증하면 좋다. 현재 구현은 closest('button')으로 부모 처리를 건너뛰므로, 이는 현재 기능 버그가 아닌 회귀 검증 공백이다.

## 대비·레이아웃 검토

- 실제 토큰은 `--scrim-rgb: 8, 20, 46`. 흰 사진 위 alpha 0.62 합성 RGB는 `(101.86, 109.30, 125.42)`이고, sRGB 선형화 후 상대휘도는 `0.1530943`, 흰 글자 대비는 `1.05 / (0.1530943 + 0.05) = 5.1700:1`이다. DESIGN의 ‘약 5.1:1’은 보수적인 근삿값이며 4.5:1을 충족한다. 그림자 효과를 대비 계산에 포함하지 않아도 통과한다.
- Home: `.home-ph__tx` 자체 배경 전체가 .62~.80이고, 56px 페이드는 `::before { bottom:100% }`로 박스 밖에만 있다. 글자는 정상 flex 흐름이며 위 padding 10px 안쪽에서 시작하므로 줄바꿈으로 높이가 커져도 페이드 영역으로 올라가는 구조가 아니다.
- Place: `.place-hero--photo .place-hero__tx`의 위 72px가 투명→.62 구간이고 padding-top도 72px다. 첫 콘텐츠와 이후 제목·메타·상태·출처는 .62 이상 구간에 위치한다. 높이는 고정 height가 아닌 min-height여서 줄바꿈 시 확장된다. 음식 예시 띠는 추가 .92 배경을 유지한다.
- 흰 상태 알약에는 최종 CSS의 `text-shadow:none`이 적용된다. 제공된 장소 스크린샷에는 상태 글자 그림자가 보이므로 이 마지막 CSS 보정까지 반영한 최신 캡처인지는 확인되지 않는다.
- 제공된 390px EN `home.png`, `place-gwc.png`, `place-mus.png` 및 `mockup/redesign/c2-home.png`, `c2-place.png`를 직접 열어 비교했다. 사진 상부 노출 증가, 원도심과 같은 대전역 코스 패널·출발 안내·시작 버튼을 확인했다. 시안과 달라진 높이와 대전역 패널은 이번 명시적 사용자 요청에 해당한다.
- 실제 360px JA/ZH 화면은 제공되지 않았다. Orca의 기존 로컬 앱 탭 두 개는 ERR_CONNECTION_RESET이고 workspace ports도 빈 목록이었다. 파일 생성 제한을 지키기 위해 서버·새 빌드·새 스크린샷을 만들지 않았다. 따라서 세 언어 실제 렌더에서 가로 넘침·글리프 경계까지 측정한 결과는 없으며, 배포 전 해당 검증이 남는다.

## 기능·접근성·범위

- 기존 `hub-station`, `hub-downtown`, `home-start` testid 유지, 새 `home-start-market` 추가. 기존 E2E는 `hub-downtown` 클릭을 사용하며 단일 ‘Start the course’ 역할 선택에 의존하지 않아 정적 계약상 충돌 없음. E2E 실행은 이번 허용 명령 범위에 없어 수행하지 않았다.
- 대전역 article 안에 native Button 하나만 있어 중첩 button 없음. article은 추가 클릭 영역이고 키보드 사용자는 내부 시작 버튼으로 같은 동작에 도달한다. h1 뒤 대전역 h2 → 원도심 h2로 제목 단계 역전 없음. 두 버튼의 동일한 이름은 각각 코스명을 aria-describedby로 연결해 보완했다.
- 공통 Button의 높이 52px·최소 터치 44px·3px 초점 외곽선, 전역 reduced-motion 규칙을 재사용한다. 기존 사진 alt·출처·야시장 조건·확인 전 안내·비제휴/가격 안내 로직은 변경하지 않았다. Place 변경은 CSS에 한정된다.
- 기존 번역 키와 코스 현지화 데이터를 재사용하며 EN/JA/ZH의 시작 버튼·출발 안내 키가 존재한다. 새 번역 패치가 없는 것은 이 task에서 정상이다.
- 기존 테스트 삭제 없음. 원도심 시작 버튼의 역할 선택을 testid로 바꾼 것은 버튼이 두 개가 된 동작에 맞는 변경이다. 소스 변경은 Home 세 파일·Place CSS·DESIGN 5장에 한정되며 task.md 등록 수정은 위 L-01과 같이 별도 확인했다. 시작 시 이미 있던 미추적 보고서·tsbuildinfo 등은 이번 작업의 수정으로 단정하지 않았다.
