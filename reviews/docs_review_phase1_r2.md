## 대체 문구·결정 일치 여부

판정의 필수 대체 문구는 의미 변경 없이 반영됐다. U-1에 따른 PRD F-03·F-04의 한국어 기준 문구는 모두 **‘현장 확인 전 · 예시 정보’**이며, T2.2는 이때 날짜를 표시하지 않도록 명확히 했다. T2.3에서도 장소 단위 상태를 쓰므로 메뉴가 없는 장소의 자리표시 날짜가 확인일로 노출되던 문서상 빈틈이 해소됐다.

C-1의 데이터 계약은 별도 T1.1b로 배정됐다. 공용 Place 타입 변경 범위와 T1.2 소유 사전 수정의 coordinator 승인 조건, 데이터·i18n 테스트 및 타입 검사 완료 조건이 명시돼 있다. T1.2에도 같은 키의 담당·검수 연결이 있어 중복 구현을 요구하지 않는다. **T1.1b의 코드 구현 완료를 이번 문서 검토로 인정한 것은 아니다.** T1.1b 자체 검토와 완료 조건은 별도다.

선택 사항이었던 E2E 6의 추가 방문 비율 확인과 topPhrases 집계 설명은 미반영 상태지만, 판정대로 미해결에 포함하지 않는다. PRD의 기존 ‘시연 전 현장 확인’ 요구는 유지되며, 이번 변경은 그 전에 공개되는 Phase 2 화면에서 확인 전 상태를 정직하게 표시하는 규칙이므로 서로 모순되지 않는다.
