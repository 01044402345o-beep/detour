## 생성 조건
- 내용: `https://01044402345o-beep.github.io/detour/` (README·PRD의 고정 배포 URL)
- 라이브러리: npm `qrcode@1.5.4` — app 밖 임시 폴더(세션 scratchpad)에 설치. **app 의존성·lock 변경 없음**
- QR 버전 3, 오류 정정 M, 여백(quiet zone) 4모듈, 색 `#151a26`(토큰 `--ink`) / `#ffffff`
- 검증 도구(같은 임시 폴더): `jsqr@1.4.0`, `pngjs@7.0.0`, 렌더링은 app의 Playwright + 설치된 Edge(channel msedge)

## 디코드 검증
| 대상 | 방법 | 결과 |
|---|---|---|
| `qr.png` | 파일을 다시 읽어 jsQR 디코드 | `https://01044402345o-beep.github.io/detour/` — **일치** |
| `qr.svg` | path를 37×37 격자로 복원 → `qrcode` 행렬과 모듈 단위 비교 + 10배 래스터화 후 jsQR 디코드 | 행렬 **일치**, 디코드 **일치** |
| `deck/index.html` 화면 | Edge로 열어 스크린샷 → jsQR 디코드. 뷰포트 1920×1080, 1280×720, 1366×768, 1024×768, 2560×1440 | 5개 모두 이미지 로드 성공·디코드 **일치**, 슬라이드가 화면 안에 들어옴(1024×768은 위아래 레터박스) |

- 작성 중 발견·수정: 첫 버전은 1920×1080 외 화면에서 슬라이드가 오른쪽·아래로 밀려 QR이 잘림 → 고정 위치 + `translate(-50%,-50%) scale()`로 수정 후 위 표 재검증.
