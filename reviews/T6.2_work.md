## 결정
- **사진 위 글자 막:** 글자 영역 전체에 `rgba(var(--scrim-rgb), .88)` 불투명 띠(≥.85), 위쪽 28px만 장식용 그라데이션(글자 없음). 상태 알약은 흰 바탕(`--ok`/`--ink` 글자).
- **사진 alt:** 사진 내용(시장 입구·스카이로드·족욕장)은 옆 글자에 없으므로 `photos.ts`의 alt를 현재 언어로 사용. 위 두 장 eager, 유성 lazy, 모두 `decoding=async`.
- **앰버만으로 의미 전달 안 함:** 대표 역은 굵은 테두리(5px vs 3px) + 큰 카드·h2로 구분, 점은 `aria-hidden` 장식.
- **한글 역 이름(대전역·중앙로·유성온천) 표시 안 함 (시안과 다름):** 화면 코드의 한글 문자열은 hardcodeCheck 위반이고, 사전은 ja/zh에 영어·한글만 값을 둘 수 없음(index.test). 대신 현지 언어 역 이름(`home.stnStation|stnDowntown|stnYuseong`: Daejeon Stn / 中央路駅 / 儒城温泉站 …). 한글 병기가 필요하면 coordinator가 `BRAND_TERMS`(T6.0 소유) 또는 데이터에 역 한글명을 추가해야 함.
- **DEMO 알약 → "Open"/"Coming later" 알약:** 시안대로. 예시 정보 안내는 코스·장소 화면 정책(6장)이 맡음.
- 권역 이름은 기존 키 재사용(`home.hubStation` = "Station & Sojedong", 시안 "Daejeon Station & Sojedong"과 약간 다름 — 값 변경 없이 유지). 유성 설명만 새 키 `home.yuseongDesc`.
- 쓰지 않게 된 `home.*` 키(hi, whereTo, pickHub, seeMap, spots, minutes, overnight*, today*, hubYuseongSub, location, search)는 지우지 않음.
- 야시장 판단 시각은 홈을 연 시각(`useState(() => new Date())`). 홈에 오래 머무는 경우 재계산은 하지 않음(코스 화면 SeasonCard가 상세 상태 담당).
