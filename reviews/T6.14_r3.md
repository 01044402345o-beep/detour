## 원고·번역·동작 검토

- 코스 2개·장소 8곳의 EN/JA/ZH 원고가 있고, 한글·가격 통화 표기 없이 모든 원고에 미확인 예시 안내가 있다. 코스 거리·시간·순서와 장소 주문 단계, 박물관 운영 시간, 면 사리 추가·계산 순서 등을 downtown/market 데이터와 대조했다. 이번 수정에서 앱 데이터·허용된 일반 배경 설명을 넘어 새로 추가한 사실 단정은 발견하지 못했다. 현장 운영 정보 자체를 실사로 인증한 것은 아니다.
- 일본어는 안내 말투와 예시 고지가 자연스럽게 정리되어 있고 중국어는 간체를 유지한다. 원고의 Phrases / フレーズ / 短句는 실제 place.tabPhrases와 일치한다. 실패 안내의 Play / 再生 / 播放도 오류 후 표시되는 버튼과 맞는다. 로마자 상호·大田/聖心堂 같은 한자 고유명사·LED/App의 실제 발음은 엔진별 청취 확인이 필요하다.
- `app/src/i18n/patches/T6.14.json`의 guide 객체를 적용된 en/ja/zh.json과 메모리에서 비교했고 세 언어 모두 완전히 일치했다. 새 guide 키 누락은 발견하지 못했다.
- 클릭 처리 안에서 await 없이 발화를 큐에 넣으며, 음성 목록이 없으면 lang 지정으로 시도한다. 목록 탐색은 voiceschanged와 2초 제한을 사용하고 재생 때 상태를 갱신한다. cancel은 전체 발화 큐를 제거하므로 오류 알림보다 앞에 두는 R2 수정은 적절하다. 참고: [MDN cancel](https://developer.mozilla.org/en-US/docs/Web/API/SpeechSynthesis/cancel), [MDN voiceschanged](https://developer.mozilla.org/en-US/docs/Web/API/SpeechSynthesis/voiceschanged_event).
- 멈춤 후 같은 문장부터 이어 듣기, 재생 중 속도 변경 시 해당 문장부터 새 속도로 재생, 완료 후 처음부터, 닫기·언어 변경·언마운트·페이지 숨김 시 중단 흐름과 테스트를 확인했다. 언어 변경은 문장 위치·재생·실패 상태를 초기화한다.
- 한국어 tts.ts를 수정하지 않았으며 두 어댑터는 전역 speechSynthesis 큐를 공유한다. 서로 재생을 선점할 때 상태 정리는 브라우저 취소 이벤트에 의존한다. 이번 검토에서 실제 기기의 양방향 선점 성공을 확인한 것은 아니다.
