# T6.13 코드 검토 R1

검토일: 2026-11-26. 판정: **수정 필요 — H 0 / M 1 / L 3**.

## M-01 — 장소 상세를 보고 돌아오면 명시적으로 고른 행선지가 다른 곳으로 바뀜

- 위치: `app/src/screens/Course/index.tsx:140–147` (`useState(null)` 및 `target` 계산), `:123` (`open`의 상세 이동).
- 재현 흐름: 원도심에서 3번을 선택 → 목록의 3번 장소 상세를 열어 정보 확인 → 코스로 돌아오기. 코스 화면이 라우트 전환으로 언마운트되어 `picked`가 사라지고, 상세 진입 때 남긴 `place_view`로 `nextStopIndex`가 4번을 반환하므로 선택·네이버 주소·Google 주소가 모두 4번으로 바뀐다. 시장 코스에서도 같은 구조다. 이는 코드와 라우팅/이벤트 기록 경로로 확인한 결과이며 브라우저 왕복 재현은 수행하지 않았다.
- 영향: 가려진 전체 이름이나 영업시간을 확인하고 선택한 장소로 걸어가려는 사용자의 의도와 실제 길찾기 목적지가 달라진다. 상세 열람을 실제 도착으로 간주하는 기존 자동 다음 정류장 규칙이 새 수동 선택까지 덮어쓴다.
- 수정: 코스별 명시적 선택을 상세 왕복 동안 복원한다(예: 코스 URL/상태에 보존). 선택하지 않은 경우에는 기존처럼 방문 기록에 따라 자동 선택하고, `Next` 표시는 계속 별도로 계산한다. 공용 store/router 변경이 필요하면 coordinator와 범위를 조율한다.
- 검증: 두 코스 각각 수동 선택 → 상세 진입 → 복귀 후 같은 선택과 두 외부 주소 유지, `Next`만 새 기록에 따라 이동하는 통합 테스트를 추가한다. 미선택 상태의 기존 자동 다음 정류장 동작도 유지한다.

## L-01 — 다음 정류장 표시가 디자인 최소 글자 크기보다 작음

- 위치: `app/src/screens/Course/Course.css:381–391`, 특히 `font-size: 10.5px`.
- DESIGN.md 3장의 최소 크기는 11.5px이고 이 배지는 예외로 지정되지 않았다. 선택과 다음 정류장을 구별하는 의미 있는 글자이므로 11.5px 이상으로 높이고 2×2 칸의 간격·배지 겹침을 재확인한다. 앰버 바탕에 진한 글자를 사용한 점 자체는 적절하다.

## L-02 — 일본어 질문에 반각 물음표 사용

- 위치: `app/src/i18n/patches/T6.13.json:11` 및 적용된 `ja.json`의 `course.pickLabel`.
- `どこへ歩きますか?`는 일본어 문구에 반각 `?`가 붙어 있다. 전각 `？`로 통일하고, 행선지 선택 질문으로 더 자연스러운 `どこまで歩きますか？`도 고려한다. 중국어의 전각 물음표와 곡선 큰따옴표, 일본어 안내문의 「」는 적절하다.
- 수정은 패치 원본을 기준으로 하고 적용 번역 파일과 일치시킨다.

## L-03 — 키보드·복귀 동작 및 E2E 완료 증거 부족

- 위치: `app/src/screens/Course/Course.test.tsx:450` 이후 신규 테스트, `reviews/T6.13_work.md` 확인 절.
- 신규 4개 케이스는 두 코스의 클릭 선택과 주소/문구 변경을 검증하지만, 라디오별 낭독 이름·화살표 이동·Tab 진입/이탈·초점 표시·방문 기록 변경/화면 복귀를 검증하지 않는다. 작업 보고에도 E2E 실행 결과가 없어 task 완료 조건의 “테스트·E2E 통과”는 아직 확인되지 않는다.
- 네이티브 radio + 같은 name + label/fieldset/legend를 사용하므로 현재 코드에서 화살표 처리가 빠졌다고 판정하는 것은 아니다. 실제 브라우저에서 화살표로 선택 및 두 링크가 함께 바뀌는지, 포커스 링이 보이는지 확인하고 결과를 남긴다. M-01의 왕복 테스트와 각 radio의 전체 낭독 이름 assertion을 보강한다.

## 기준 충족 및 회귀 검토

- T6.13 소유 코드 3개, 번역 패치, DESIGN.md 코스 항목, prd.md F-03·S02 및 버전 이력, task 항목의 변경을 확인했다. 세 언어 JSON 변경은 패치의 3개 키 적용 결과와 일치한다. 현재 diff에서 T6.13에 관계없는 코드 수정은 발견하지 않았다. 공유 번역 파일의 실제 작성 주체/적용 명령 이력은 diff만으로 확정하지 않았다.
- 라디오 그룹은 fieldset/legend로 이름을 갖고, 각 label 안 전체 장소명과 sr-only 정류장 순번이 낭독 이름을 구성한다. 숨긴 input은 display:none이 아니며 네이티브 키보드 동작을 사용할 수 있다. 선택은 파랑 테두리·번호 채움, 다음 정류장은 텍스트가 있는 앰버 배지로 구분된다. 다만 실제 보조공학 낭독 및 브라우저 키보드 시험은 하지 않았다.
- 새 선택 칸은 `min-height: var(--touch)`(44px), `:has(input:focus-visible)`의 3px 초점 링을 사용한다. 글자 색 조합은 기존 ink/mute/blue/tint 토큰으로 4.5:1 기준과 부합하며 앰버에는 ink 글자를 사용한다. 전역 reduced-motion 규칙이 새 transition에도 적용된다.
- 두 코스의 EN/JA/ZH 스크린샷 6장과 `mockup/redesign/c2-course.png`를 직접 열어 비교했다. 요청에 따른 2×2 행선지 선택 추가가 확인되며 선택 3번과 Next 1번이 분리되어 보인다. 가로 넘침은 보이지 않고 안내의 전체 장소명도 읽힌다. EN 및 긴 JA 이름의 말줄임은 명시된 디자인 요구다.
- 캡처의 고정 영역은 약 244 CSS px로 목록의 첫 화면 노출을 크게 줄인다. 그러나 dock이 `position: sticky`인 정상 흐름 요소이고 notes가 그 앞에 있으며 하단 여백도 있어, 코드상 목록/노트가 영구히 가려지는 오류는 확인하지 않았다. 제공 캡처는 상단 상태뿐이므로 스크롤 끝·더 낮은 높이·확대 글꼴에서의 실제 도달성까지 확인한 것은 아니다.
- 기존 사진/빈 alt/출처/음식 예시 표시와 확인 전 요약·혼합 표시 로직은 변경되지 않았다. 새 사진이나 사진 위 글자 막도 추가되지 않았다.
- `screen-course`, `stop-<id>`, `start-walking`, `google-maps` 계약 유지. 기존 E2E `support.ts:102–109`의 정류장 상세 이동 selector도 유지된다. 외부 지도 URL 생성 함수와 이벤트 기록 코드는 변경되지 않았고 선택 클릭이 별도 방문 이벤트를 만들지 않는다.
- 기존 테스트 삭제 없음. 안내 변경에 필요한 dirNext 기대 3곳만 dirTo 기대로 갱신했고 선택 테스트 4개를 추가했다.

검토 시점에는 다른 task를 포함한 tsc/lint 오류도 없었다. E2E는 이번 read-only 지시의 허용 실행 목록에 없으므로 실행하지 않았으며, 정적 계약 확인만 수행했다. 번역 패치 스크립트·build·commit·push는 실행하지 않았고 이 보고서 외 파일은 작성하거나 수정하지 않았다. 제공 스크린샷은 작업자의 산출물이며 이번 검토에서 새로 촬영한 것은 아니다.
