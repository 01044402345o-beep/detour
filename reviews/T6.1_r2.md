- 정지 순간 완성 상태로 바뀔 때 짧은 카드/휴대폰 CSS 전환이 남을 수 있으나, 무한 파형·단계 진행·자동 장면 전환은 멈춘다. R1의 지속적인 움직임 결함은 해결되었으며, reduced-motion에서는 이 짧은 전환도 제거한다.
- 행 배경이 불투명이므로 안내판·무대의 반투명 배경에 따라 수량 대비가 달라지지 않는다. 앰버 글자색은 제거되었고 진행 표시·밑줄·그림의 경로선 등에만 남는다.

## 완료 조건·기능·접근성

- 로고 → 파란 안내판 → 제목·필요성 → 언어 선택·발음 안내 → 시작 버튼·하단 문구 구성을 유지한다. 안내판은 세 장면과 번역 설명, 4.4초 순환, 수동 선택 시 정지, 재생/정지 버튼을 제공한다. 특정 메뉴 예시 문장은 없다.
- `/lang`, `screen-lang`, `lang-en|ja|zh`, 시작 버튼 키 `lang.start`가 유지된다. `app/e2e/support.ts:61`의 chooseLanguage가 사용하는 라벨 클릭·버튼 이름·홈 도착 계약과 일치한다. 실제 E2E 실행은 하지 않았다.
- 즉시 언어 저장·문구 갱신, 미선택 시작 시 EN 저장, 발음 안내, 탭바 없음, 라우터의 screen_view 1회 기록 테스트가 유지되고 통과했다. R1 수정이 라우팅·저장·이벤트 기록에 새 동작을 추가하지 않는다.
- 네이티브 radio, 선택 탭만 Tab 진입, 방향키/Home/End와 초점 이동, 탭/패널 연결, 재생 버튼의 동작 이름 전환, 자동 재생 중 aria-live off·정지 후 polite가 유지된다. 타이머는 정지·언마운트 시 정리된다.
- 탭·재생·언어 선택의 최소 동작 영역은 공용 44px 토큰, 시작 버튼은 58px다. 언어 선택은 파란 초점선, 파란 안내판 내부는 흰 초점선이다. 후자는 R1과 같이 배경 대비를 확보하는 처리로 수용한다.
- 주요 색·글자 토큰과 400~700 굵기를 사용하며 장식용 그라데이션은 없다. 사진을 쓰지 않아 사진 출처·막·사진 alt 규칙은 해당하지 않는다. 장식 장면은 aria-hidden이고 의미는 별도 설명이 전달한다. 실제 장소·가격·알레르기 정보가 없어 확인 전 안내 정책을 새로 적용할 부분도 없다.
- EN/JA/ZH 패치의 42개 leaf 값을 읽기 전용으로 적용 사전과 비교해 모두 일치했다. 누락·미적용을 발견하지 않았다. 화면과 언어 항목에 lang 속성이 있고 JA/ZH 본문에 줄바꿈 규칙이 있다.
- 작업 보고의 수정 파일은 소유 범위와 맞고 공용 사전 적용은 허용된 예외다. 공유 작업 트리의 다른 변경을 T6.1에 귀속할 증거는 없다. 작성자별 귀속 자체는 공유 diff만으로 확정할 수 없다.
