## 2. 사용자 결정 및 신규 문제 확인

- **U-1:** 고정된 앱 버전의 녹화 클립을 사용하므로 Phase 3에서 수정 중인 컴포넌트를 직접 따라가던 읽기 의존을 제거했다. Phase 4 수정 시 기존 녹화본을 단순 재렌더링하는 대신 영향 장면을 갱신하도록 했다. 영향 없는 장면을 유지하는 경우에는 장면별 클립 목록과 영향 없음 기록을 함께 읽으면 된다.
- **U-2:** 0.3절의 허용 목록 설명과 T2.7 Git 항목 모두 ‘소스 코드만’ 공개로 일치한다. 실제 .gitignore 변경은 coordinator의 T2.7 준비 작업으로 지정돼 있어 이번 문서 수정에서 구현하지 않은 것을 미해결로 세지 않는다. 구현 때 녹화·음성 등 소재를 지정 제외 경로에 두고 실제 추적 대상이 소스만인지 확인해야 한다.
- **U-3:** 영어 Kokoro 오프라인 TTS·한국어 edge-tts 온라인 음성으로 방법을 구체화했다. 259행의 사용자 이용 조건 확인과 253행의 Remotion 라이선스 확인은 후속 작업으로 남아 있다. 이번 문서 검토가 해당 사용 조건을 충족한다고 판정한 것은 아니다.
- **검증·소유권:** Phase 2.5의 구체적인 대체 절차를 0.1절이 참조하는 0.3절에 뒀으므로 앱 E2E·Pages 배포를 중복 요구하지 않는다. video 전용 소유와 coordinator의 공용 파일 변경 역할이 유지됐다. 영상 소스의 dev 커밋은 영상 완료 자체가 main 배포를 촉발하지 않는다는 뜻으로 읽으며, 이후 정상 앱 배포 때의 이력 병합까지 금지하는 규칙으로 해석하지 않는다.
- **기존 수정:** 현재 176행의 STT unsupported 예외는 유지돼 T0.2 R2 판단을 뒤집을 변경이 없다.

변경된 문구 사이에서 추가 기능 누락, 소유권 충돌, 실행 순환 또는 검증 불가능한 완료 조건을 발견하지 못했다. 영상 1080×1920·120초 이하, 표기 검수, 커밋·클립·산출물 기록은 후속 T2.7에서 확인 가능한 조건이다.
