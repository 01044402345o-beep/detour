# T1.5 음성 어댑터 R2 수정 내역 — Claude 작성자

기준: `reviews/T1.5_r2_verdict.md` R2-L-01 (L, 타당 — 빈 목록 보존을 `init()` 2초 재확인으로 제한)
수정 파일: `app/src/speech/tts.ts`, `tts.test.ts` (그 외 변경 없음)

## 코드 (`tts.ts`)
1. `refreshVoice(): boolean` — 비어 있지 않은 목록을 실제로 봤으면 `true`, 빈 목록이면 `false`이고 `state`·`voice`는 바꾸지 않음(지침 1).
2. `init()` — `refreshVoice() && state === 'ready'`일 때만 바로 반환. 빈 목록이면 과거 ready여도 `findVoice()`로 최대 2초 재확인 → 계속 비면 기존 코드대로 `voice=null`·`no-korean-voice` 확정. `searching` 합치기는 유지(지침 2).
3. `speak()` — `const seen = refreshVoice()`; `seen && voice`일 때만 `u.voice` 지정. 빈 목록이면 `lang='ko-KR'`만. await·타이머 없음(사용자 활성화 보존, 지침 3).
4. 헤더 주석·`refreshVoice` 주석에 "빈 목록은 일시적으로 보고 판단 유지, 다음 `init()`에서 최대 2초 재확인 후 확정" 명시(지침 4). 상시 `voiceschanged` 구독은 도입하지 않음(지침 5).

## 테스트 (`tts.test.ts`, 22 → 25)
- (수정) "목록이 일시적으로 비면…": [ko]→[] 후 `speak()`의 `u.voice`는 null, `lang`은 ko-KR, `getState()`는 `ready` 유지.
- (신규) [ko] ready → [] → `init` → 2000ms → `no-korean-voice`, 이어서 `speak()`의 `u.voice` null.
- (신규) [ko] ready → [] → `init` → 1000ms에 `setVoices([ko])` → `ready` 회복, 이후 `speak()`가 ko 지정.
- (신규) [ko] ready → [] → `init` 직후와 1999ms 시점에 `getState()`는 `ready`(보자마자 강등하지 않음).
