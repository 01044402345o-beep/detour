# 대전 디투어 (Daejeon Detour)

외국인 방문객용 대전 원도심 동선·주문 카드·현장 한국어 웹앱입니다. 심사 시연용 데모입니다.

- 배포 URL: https://01044402345o-beep.github.io/detour/

## 실행 방법

```sh
cd app
npm ci
npm run dev
```
